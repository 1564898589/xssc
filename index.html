〇公司一句话与实力清单见客户第一分钟

客户问"你们是做什么的"，30 秒内讲完这一段，不卑不亢、全是实打实的东西

一客户行业的分类词最优先掌握

1.1 一次设备 / 二次设备

  • 一次设备：直接通过高压大电流的设备——变压器、断路器、隔离开关、互感器、母线。
  • 二次设备：不直接走大电流，做"测量、控制、保护、信号"的低电压小电流设备——继电器、变送器、温控器、信号报警器、开关电源、端子排。
  • 你卖的全部是二次元件。客户说"二次回路""二次图"，就是你的产品所在的那部分电路图。
  • 一次图 / 二次图：一次图画的是主电路（哪根母线接哪个断路器）；二次图画的是控制保护回路（继电器、变送器、指示灯、端子怎么接）。你的产品出现在二次图上。客户说"把你们型号反馈给画图的"= 设计院正在把你的型号画进二次图，好消息。

1.2 成套厂 / 本体厂

  • 成套厂：把断路器、互感器、继电器等买回来，组装成开关柜（KYN28、GGD、环网柜）卖出去。他们没有选型权，柜内元件按设计院图纸或业主指定采购——这就是你排除他们的原因。
  • 本体厂：自己制造设备本体（如断路器操作机构、变压器绕组），控制回路自己设计、元件自己选——选型权在他们手里，是你的目标客户。
  • 判断口诀：问对方"你们的电气图纸是自己设计院画的还是外来的？"自己画 = 有选型权。

1.3 电压等级

  • 日常术语：0.4kV（低压）/ 10kV / 35kV / 110kV / 220kV / 500kV。
  • 数字越大电压越高。10kV、35kV 是工业用户和新能源接入的常见等级——也是你客户最集中的领域。
  • 客户说"我们做 35kV 以下"，意思是他的产品用在 35kV 及以下电网。

1.4 kVA / kW

  • 变压器容量单位。SCB10-1000kVA/10kV = 树脂浇注干变、设计序号10、容量1000千伏安、电压10kV。
  • 一台 1000kVA 干变大约要配 1 套温控器（DTC/TC）——听到客户报年产能多少 kVA，心里就能估算温控器需求量。

1.5 变压器型号怎么读（见客户必备）

  • SCB / SCBH：S=三相，C=环氧树脂浇注，B=箔式绕组，H=非晶合金（加H=节能款）。
  • S11 / S13 / S20：油浸式变压器，数字越大越节能。
  • 干变 = 干式变压器（空气自冷/风冷，不泡油）；油变 = 油浸式。干变必配温控器，油变配油面温控计（较多用别的产品）——这就是你主攻干变厂的原因。
  • 箱变 = 箱式变电站（把变压器+开关柜装进一个铁箱子里）。美式箱变/欧式箱变是两种结构风格。

1.6 电网侧：国网 / 南网体系（客户最常报的身份）

  • 国网 / 南网：国家电网（覆盖全国 26 省）/ 南方电网（广东、广西、云南、贵州、海南）。客户说"我们是国网的""南网的"= 电网系统的人。你有国网/南网入网资质，这是和电网体系客户对话的第一张牌。
  • 省公司 / 地市供电公司 / 县公司：电网的三级管理层级。省公司定全省采购政策；地市局是实际用货和验收单位；县公司和你接触最多但权限最小。先搞清楚谁说了算再决定找谁。
  • 主网 / 配网 / 农网：电网三大业务板块。主网 = 35kV 及以上（变电站、输电线路）；配网 = 10kV 及以下（配电室、开关柜、环网柜）；农网 = 农村电网改造。你的产品三块都进：主网要求高（型式试验/业绩），配网量大，农网走量低价。
  • 三产 / 集体企业 / 多经：电网下属的"旁系企业"——送变电公司、电力安装公司、电力设计院、物资公司。大量施工、安装、运维、改造是它们干的，很多实际采购也走它们——这是绕开电网集采、直接对接的口子。
  • 国网商城 / 电商化采购：国网系统的线上采购平台。客户说"这单走国网商城"= 先完成平台入驻，价格流程全部线上化。

1.7 发电侧：电厂与新能源投资商（第二大类客户）

  • 五大发电集团：华能、大唐、华电、国家电投、国家能源——发电侧央企，旗下火电/水电/新能源电厂遍布全国。
  • 六小豪门：国投电力、华润电力、中广核、三峡集团、中核集团、中节能——新能源投资主力，光伏风电储能的电站业主大多是它们。
  • 电源侧 / 电网侧：发电的一端（火电、水电、光伏、风电、储能）叫电源侧；输配用电的一端叫电网侧。客户说"我们做电源侧"= 面向发电厂和新能源场站供货。
  • 新能源投资商 / 电站业主：出钱建光伏风电储能站的主体——设备采购多走 EPC 和集成商，但品牌指定权在业主手里，业主点头比集成商点头更值钱。

1.8 按"谁出钱、谁选型"分客户类型（销售先分清这个，打法完全不同）

  • 配套型客户（BOM 型）：他们的产品里固定装你的元件（干变厂装温控器、开关柜厂装继电器）——单小但连续，进了 BOM 就锁定，最值得深耕，是你现阶段的主力。
  • 项目型客户：一单一议、跟着项目走（EPC、总包、招标项目）——单大但不连续，要盯项目信息、拼资质和价格。
  • 渠道型客户：经销商、贸易商，转手赚差价——价格敏感、忠诚度低，但能铺量，适合走量。
  • 终端用户 / 业主：最终用货的（电网公司、工厂、电站）——有品牌指定权，但采购走招标或集采，周期长。

1.12 前期拓客：先找对客户（新人第 1~2 周只干这一件事）

拓客不是撒网，是"选矿"——你 90% 的时间该花在 10% 能下单的客户身上。判断标准一句话：谁的图纸里能写进你的型号，谁就是第一优先级；选型权在哪，你就在哪使劲。记住：成套厂的图纸是设计院画的、业主定的，他自己写不进你的型号——所以成套厂永远不是第一优先级。（结合 1.8 客户类型看）

优先级客户是谁为什么是它打法目标
P0本体厂 / 整机厂（干变厂、断路器机构厂、直流屏厂、箱变厂）设备图纸自己出、二次元件自己选型，能写进你的型号、进 BOM送样 → 进图纸 → 进 BOM（见 6.6）
P1设计院二次图、技术规范真正出自这里——图纸写你型号，单就跑不掉混脸熟 + 送资料，让新图纸想到你
P2终端 / 业主（国网、南网、工厂、电站、项目方）招标技术规范可指定品牌，说了算但周期长品牌印象 + 让技术规范写上你
P3新能源集成商（光伏 / 储能舱 / 充电桩）整舱设计自己选型，量在起来成套配套报价，一单配齐（见 4.8）
P4成套厂（KYN28 / GGD 柜厂）按图施工，选型权在设计院 / 业主——他写不进你的型号别当主力：已成单走流程 + 当情报线

还有一个 贸易商（渠道）：不选型、只压价，留联系方式即可，不投入。

找错客户的 5 个典型样子（新人最常犯，白忙一个月）：

  • 把成套厂当 P0 磨——图纸是设计院画的、业主定的，他再想用你也写不进图。跑十家成套厂，不如搞定一张图纸（老销售的实战教训）。
  • 在贸易商身上磨一周——他不选型、只压价，聊得再深也进不了 BOM。
  • 找设计院要订单——设计院不下单，你的目标是"图纸上出现你的型号"。
  • 找终端业主推销，却不跟图纸——业主说了算但周期长，图纸源头在设计院，两头都得顾。
  • 撒网群发不聚焦——二次元件客户就三类人：画图的（设计院）、自己出设备的（本体厂/集成商）、按图施工的（成套厂），重心永远在前两类。

去哪找 P0/P1（获客渠道，按效率排）：

  • 中标公告：搜"干变 中标 / 直流屏 中标 / 断路器 中标 / 储能舱 中标"，顺着中标单位找本体厂、集成商——谁中标谁有活；同时记下公告里的设计单位，那是图纸源头。
  • 老客户转介绍：已成交的本体厂 / 集成商技术部、采购部的人，认识十个同行，让他介绍比陌拜高效十倍——前期每成交一家，都问一句"您还认识做同类设备的朋友吗"。
  • 行业展会：输配电、电力设备类展会，本体厂、集成商、设计院都来——带样册换名片，回来后一周内跟进。
  • 行业名录：干变厂 / 直流屏厂 / 箱变厂 / 断路器厂名录，按地区圈定，挨个电话约拜访。
  • 设计院渠道：认识设计院工程师，新项目出图时想到你——图纸上写型号就赢了一半。
  • 电商 / 集采平台：国网、南网电商平台看采购目录和供应商名录，找入围机会。

对方一句话，30 秒判断值不值得深聊（结合 1.9 自称词）：报"我们是做干变的 / 做直流屏的 / 做断路器的 / 做箱变的"→ P0 本体厂，深聊约拜访；报"我们是做储能舱的 / 做光伏集成的"→ P3 集成商，深聊；报"我们是做开关柜的 / 做柜子的"→ P4 成套厂，先别急着约，问三句：图纸谁画的？柜内元件现在用谁家的？能不能跟设计院 / 业主提型号？能 → 当情报线 + 配合线；不能 → 留名片走人，别投入；设计院 → 给资料混脸熟，目标是图纸；贸易商 → 留联系方式，不投入；终端业主 → 客气接待，问清他的供应商是谁，找机会切进去。

2.1 继电器家族（型号最多、柜内用量最大）

  • 中间继电器（RC 系列）：把一个小信号放大成多个输出的"多路开关"。柜子里用量最大的品种。一个中间继电器上通常有 2~8 对触点。RC 系列分五档：
    • RC 常规型（接点 2Z/4Z/6Z/8Z 可选，8A 250VAC）
    • RC-F 快速型（动作时间 ≤7ms，跳合闸等要求"快"的回路用，8A 250VAC）
    • RC-V 直流型（可直接通断直流负载，接点 2H/4H/2Z，10A 220VDC）
    • RC-M 继电器模组（可满足各种电压、接点要求的组合件，5A 250VAC）
    • RC-P 可拔插型（可拔插结构、体积小、可不停电更换，接点 2Z/4Z，5A 250VAC）
  • 触点：继电器里真正通断电的金属片。"常开（NO/H）/常闭（NC/D）/转换（Z）"= 不工作时断开/导通/公共端切换。客户问"几常开几常闭"，你要答得上来——型号后缀里的 2Z、4H 就是这个意思（如 RC-V 2H/4H/2Z）。接点类型表示法：H-常开，D-常闭，Z-转换。
  • 触点容量：触点能安全通断的最大电流/电压，如 8A 250VAC。客户选型第一问常常就是触点容量——带多大负载、什么负载类型（阻性/感性）。感性负载（线圈、电机）通断瞬间电流是额定的几倍到十几倍，所以同一对触点带灯泡没问题、带接触器线圈就要降容用。
  • 抗干扰继电器（RAI / RAI-V）：强电磁环境（变频器旁、矿下、试验场）用的加强版——启动功率 >5W、防反接、防烧、持续 220VAC 工频不误动、动作电压（55%~65%）UN、动作时间 10~35ms。RAI-V 直流负载型（动作电压 55%~80%UN，可切直流负载，10A 220VDC）。
  • 双位置继电器（RDP 系列）：记住"合闸位置/跳闸位置"两个状态，失电也不忘。用于位置指示和回路监视。分四档：RDP（脉冲控制，线圈不可持续通电；动作/复位线圈不可同时上电）、RDP-E（互锁型，脉冲/持续通电均可）、RDP-S（单线圈，每通电一次翻转一次状态）、RDP-L（LOCKOUT 型，带就地复位和指示灯，8A 250VAC，其余 5A 250VAC）。
  • 防跳继电器（RL-TBJ）："跳"=跳闸。防止断路器在故障时反复分合（跳跃）烧毁，电流启动、电压保持。断路器厂/操作机构厂的刚需。
  • 直流操作继电器（RL-TBJ-DW）：用于断路器保护回路，防跳跃 + 跳合闸位置指示，8A 250VAC。
  • 电流启动继电器（RL-I）：电流启动，8A 250VAC。
  • 合闸保持继电器（RL-HBJ）：电流启动并自保持，8A 250VAC。
  • 跳合位监视继电器（RL-THW）：监视断路器跳闸或合闸位置，8A 250VAC。
  • 电压启动电流保持继电器（RL-UI）：电压启动、电流保持，多种接点可选，8A 250VAC。
  • 断路器回路监视继电器（RL-CBS）：同时监视跳闸回路和合闸回路，8A 250VAC。
  • 电源监视继电器（RL-PSS）：监视辅助电源，有电立即动作、失电延时返回，8A 250VAC。
  • 非全相保护继电器（RN-FB）：分相操作的大断路器（220kV+）三相可能只跳开一相，非全相运行危害电网——RN-FB 监视三相位置、延时跳三相，集成自检/复位按钮。六大特点要能背：启动功率≥5W；220V 工频交流持续输入不动作、无噪声；-40~70℃内动作电压 55%~65%UN；线圈防反接（各电压等级均支持反向 220VDC 持续输入）；防烧（允许持续输入小于动作值的电压）；集成自检和复位按钮，8A 250VAC。
  • 防跳及低气压闭锁继电器（RN-FT）：防跳 + 监视断路器 SF6 气压二合一，气压低至闭锁值时闭锁分合闸，带动作指示灯——一个继电器顶两个功能位，8A 250VAC。
  • 电压继电器（RMY）：单相/三相过压、欠压、不平衡保护。RMY-K 是无源型（不需要辅助电源，8A 250VAC）、RMY-T 是同步检查继电器（并网/备自投合闸前检查压差、角差、频差）。
  • 电流继电器（RML）：单相/三相过流保护、三相电流不平衡保护，定时限。RML-F 交流反时限、RMF-F-DC 直流反时限（电流越大跳得越快），均 5A 250VAC。
  • 整定值 / 整定范围：客户调的保护门槛数字（如"过流整定 5A"）；整定范围 = 这个门槛能调的最小~最大区间。报型号时客户常说"我要 5~10A 可整定的"。
  • 电源切换继电器（RVS 系列）：两路电源自动切换——RVS 双交流（AC1 优先，失电立即切 AC2、恢复立即切回，8A/16A 250VAC）、RVS-DC 双直流（DC1 优先，10A 220VDC）、RMS 精确切换模块（AC1 电压波动超范围就切，恢复且稳定一段时间才切回，5A 250VAC、切换功率≤1000VA）、RVSD PT 电压切换（双母线供电系统，3A 250VAC）、RVSD-TQ 同期电压切换装置（自动判断断路器/刀闸状态切换同期电压，3A 250VAC）。
  • 时间继电器（RT 系列）：收到信号后"延时"才动作。RT（上电延时/掉电延时/脉冲展宽三模式，有辅助电源，5A 250VAC）、RT-NP（无源无需辅助电源，启动功率>5W 可选，8A 250VAC）、RT-E-NP（无源带显示、体积小，5A 250VAC）、RT-X（循环定时，按设定时间反复动作/返回，5A 250VAC）。
  • 跳闸 / 合闸：断路器的"分 / 合"。客户说"跳闸回路"，就是控制断路器分闸的二次回路。
  • 辅助电源：给二次设备自身供电的电源（如 DC220V / AC220V / 85~265VAC 宽范围）。问清客户柜内辅助电源等级，直接决定你推荐哪个规格。

2.2 变送器家族（把现场量变成标准信号）

  • 变送器：把电流、电压、温度、挡位等信号转换成标准信号（4-20mA、RS485）送给仪表/后台。4-20mA 是工业标准模拟量信号——为什么是 4 不是 0？因为 0mA 意味着"断线"和"零值"分不清，4mA 是"活着"的最小信号。
  • 电量变送器（TE）：把电压/电流变成 4-20mA 或 RS485，配电柜"遥测"上传用。
  • 温度变送器（TT）：接 PT100、CU50 等测温电阻，把温度变成 4-20mA 远传后台。
  • 信号变送器（TS）：输入 4-20mA、RS485，输出 4-20mA、RS485——做信号隔离与变换的（转换信号制式、隔离干扰）。注意区分：TT 管"温度→4-20mA"，TS 管"信号→信号"（隔离/变换），别搞混。
  • 温湿度变送器（TTH）：把温湿度信号变成 4-20mA，柜内环境监测上传用。
  • 挡位变送器（TG）：把有载调压变压器的挡位变成 4-20mA 远传——电网调度要看主变在几挡。
  • RS485 / MODBUS：工业通信的"普通话"。变送器带 RS485 = 可以直接挂到客户的通信管理机上，走 MODBUS 协议被后台读取。客户说"要上后台""走通信"= 问带不带 RS485。

2.3 温控与温湿度家族（干变和柜子的"守护神"）

  • 干变温控器（DTC/TC）：干变的"体温计+守护神"。三相绕组各埋铂电阻（PT100）测温 + 第四路（环境或铁芯），超温先告警、再启动风机、最后跳闸。
  • 温控器（THC/THC-E）：采集一组温湿度信号，输出加热器、风扇、越限告警或 RS485 可选。THC-M 多功能型可接两组温湿度、输出两路模拟量。
  • 风机报警器（TCC）：监视干变冷却风机——输入温度信号或 CT，输出风机控制 + 风机断线告警。风机坏了干变会过热，客户常忽略这个测点——这是你的提醒话术。
  • 热电偶采集器（TK）：四路热电偶输入、四路超温告警接点——电厂、工业窑炉类高温测点用。热电偶 = 高温测温元件（几百上千度），和 PT100（中低温）分场景。
  • PT100 / CU50：最常见的测温电阻型号，PT100 测温范围宽（-40~200℃+）、CU50 便宜。必记住：客户说"埋的是 PT100"= 你接 TT/DTC 都能配。

2.4 信号报警家族（故障汇总的"喇叭"）

  • 信号报警器（FA/FA-I）：把分散的故障信号汇总报警——支持 8/16 路输入，可选 8/16 路继电器开出。FA 分体式（主机和显示分开装）、FA-I 一体式。驱动光字牌、警铃、把事故信号送后台。
  • 光字牌：柜门上发光的报警窗，写"断路器跳闸""SF6报警"等字样——信号报警器的下游负载。

2.5 电源与变压器家族（二次设备的"饭"）

  • 开关电源（YDSP）：把交流 100~240V（交直流通用）变成稳定的直流（110VDC/220VDC）给二次设备供电。功率分 120W/240W/600W/1000W。柜内直流元件越多，开关电源需求越大——和继电器是捆绑关系。
  • 二极管冗余模块（DPM）：两台开关电源并联互为备份，一台坏了另一台顶上，重要负载（保护、监控）不掉电。客户说"供电不能断""要冗余"= DPM 的机会。
  • 控制变压器（XF）：电压转换（常见 380V 转 100V），负载阻抗≥50K、精度 1%、单相三相可选——给进口设备/仪表/特殊电压等级负载供电用。

2.6 读型号：看一眼前缀就知道是什么（背家族缩写）

  • 第一个字母决定家族：
    • R 开头 = 继电器家族：RC 中间、RDP 双位置、RMY 电压、RML 电流、RL- 断路器保护、RN- 集成模块（非全相/SF6闭锁）、RVS/RMS 电源切换、RT 时间、RAI 抗干扰——看到 R 就知道是继电器，再按第二个字母归位。
    • T 开头 = 温度/变送家族：TT 温度变送、TS 信号变送、TG 挡位变送、TTH 温湿度变送、TC/TCC/TK 温控测温。
    • TE = 电量变送（电→信号，不是温度，别和 TT 混）。
    • THC = 温湿度控制器（本地自动动作）；DTC = 干变温控器。
    • F 开头 = 信号报警：FA / FA-I（故障汇总）。
    • Y 开头 = 电源：YDSP 开关电源；DPM 冗余模块；XF 控制变压器。
  • 后缀代表"变种"（认后缀能答上"这是哪一档"）：
    • -F 快速（RC-F ≤7ms）或反时限（RML-F）；
    • -V 直流负载型（RC-V、RAI-V）；
    • -E 增强/带显示（RDP-E 互锁、RT-E-NP 带显示、THC-E）；
    • -M 模组/多功能（RC-M、THC-M）；
    • -NP 无源型（RT-NP、RT-E-NP，不需辅助电源）；
    • -S 单线圈（RDP-S）；-L 锁存/带指示灯（RDP-L）；
    • -DW 直流操作（RL-TBJ-DW）；-DC 直流型（RVS-DC、RMF-F-DC）；
    • -T 同步检查（RMY-T）；-K 无源型（RMY-K）。
  • 实战用法：客户电话里报"RL-TBJ-DW"，你 1 秒反应"断路器防跳、直流操作型"——比翻目录快，专业感直接拉满。

三竞品与"邻居"产品听得懂别人在用什么

  • 微机保护装置（微保）：用芯片程序实现保护功能的"电脑版继电器"，一块屏替代几十个继电器。成套厂大量用它，所以你排除微保用户——但注意：干变本体厂即使用微保测温保护，风机启停和简单联锁仍常保留独立温控器。
  • RC-P / 可拔插组件：国际品牌（如 Phoenix/UE 系列）做的插拔式接口继电器，插在底座上可不停电更换。成套厂图纸常用——我们的 RC-P 就是对标替代它。
  • PLC：可编程逻辑控制器，"工业电脑"。它和继电器是部分竞争、部分共存关系（终端执行回路仍需继电器隔离放大）。
  • 接触器：长得像继电器、但用来通断大电流电机的"大力士"。别和继电器混淆：继电器传信号，接触器带电机。
  • 断路器 / 负荷开关 / 隔离开关：断路器能断故障电流；负荷开关只能断正常电流；隔离开关只做可见断口没有灭弧能力。它们的操作机构里都有二次回路=继电器客户。
  • 互感器（CT/PT）：把大电流/高电压按比例缩小给仪表保护用的小变压器。CT=电流，PT=电压。变比：如 600/5 = 一次600A变二次5A。客户说"配600/5的CT"就是这个意思。
  • SVG / SVC：无功补偿装置（动态/静态），电容器+电抗器+控制柜的组合，柜内继电器用量大。
  • UPS / EPS / HVDC：不间断电源/应急电源/高压直流——数据中心配套电源，二次元件大户。
  • PCS / BMS：储能变流器 / 电池管理系统。储能行业两大核心设备，都带大量控制柜。
  • DTU / FTU / TTU：配网自动化终端（站所/馈线/配变），配电自动化客户的主产品。
  • 四遥：遥测、遥信、遥控、遥调——电网远程监控的四种功能，是"电力物联网"的老词。遥测=变送器的活、遥信=信号继电器/报警器的活——听到"四遥"就想到变送器+信号类两条线。

四应用设备扫盲你的产品都装在哪些柜子里 · 跑客户必背

客户张口就是"KYN28 二次室""直流屏控母""汇控柜""凝露加热""温度上后台"——这一章让你立刻反应出：那是你哪个产品的家，以及它在里面干什么活。

先记住一条链：电从哪来到哪去。发电厂 → 升压站（110/220kV 高压远距离送电）→ 变电站逐级降压 → 10kV 配电室 → 变压器降到 0.4kV → 工厂/楼宇/家庭。你的产品全部落在这条链的"变电站 → 配电室 → 末端设备"这一段（10kV 及以下为主）。客户嘴里任何一个柜子、任何一句话，都能在这条链上找到位置——先定位它在链条哪一环，就知道该聊什么、该推什么。这条链背下来，你就比 80% 的同行"懂行业"。

4.1 先搞懂三个"地方"（客户的一切都发生在这三个地方）

  • 变电站：电网的"大枢纽"，电压等级高（35kV 及以上），里面一排排间隔（间隔 = 一个完整的进线/出线单元，含一面开关柜或一套设备+保护）。电网公司建的。
  • 配电室 / 配电房：工厂、楼宇、小区里的"小枢纽"：10kV 进来，经变压器降到 0.4kV 分给各车间各楼层。你客户的柜子和干变，最终大部分装在这里。
  • 开闭所：城市里常见，不降压、只做分合分配的 10kV 中转站（把一路 10kV 分成几路再送出去）。
  • 派生词：升压站（新能源场站/电厂里把电升到 35kV/110kV 送出去的变电站——光伏、风电场必配）；预装式变电站/预制舱（把二次设备整舱在工厂装好，拉到现场吊装——新能源场站主流做法，舱内二次元件在工厂预装=本体厂/集成商的选型权）。
  • 新能源场站（现在增长最快的四个场景）：光伏电站 = 光伏板阵列 + 汇流箱 + 逆变器 + 箱变 + 升压站；风电场 = 风机（机舱 + 塔筒）+ 箱变 + 升压站；储能电站 = PCS 舱 + 电池舱 + 升压站；充电场站 = 箱变 + 充电桩群。它们本质是"没有传统变电站的配电 + 升压"组合，二次元件需求跟传统变电站同级甚至更高——新能源客户是目前最肥的客户群，且选型权常在集成商/本体厂手里，正是你的目标。

4.2 柜子全家福（一排配电柜从左到右的完整顺序）

一条典型 10kV 配电室的柜列：进线柜 → 计量柜 → PT柜 → 出线/馈线柜（多面）→ 联络柜 → 无功补偿柜 → 直流屏 → 通信柜

  • 开关柜（总称）：装断路器+二次元件的柜子统称，高压柜（10~35kV）和低压柜（0.4kV）都算。柜 vs 屏：配电现场叫"柜"（开关柜、直流柜），电站里立起来一排的专业设备叫"屏"（保护屏、直流屏、远动屏）——本质都是"柜子+二次设备"。
  • KYN28（中置柜）：最常见的 10kV 金属铠装移开式开关柜。K=铠装，Y=移开式，N=户内，28=设计序号。断路器装在手车上（可像抽屉一样拉出检修），中置=手车在柜子中间层。柜顶正面那格叫"继电器室/二次室（低压室）"——你的中间继电器、信号继电器就住在这里。 客户说"二次室空间太挤"= 小型化/可拔插结构的切入点。我们在这：RC/RC-P 中间继电器、RT 时间继电器、THC 温湿度控制器（防凝露）、YDSP 开关电源。
  • XGN / HXGN（固定式柜/环网柜）：XGN=固定式金属封闭柜（断路器固定装，检修要停电）；HXGN=环网柜，体积小、装 SF6 负荷开关，城市配网"环网"主干用。环网柜空间更小，小型导轨式继电器/温湿度控制器（THC 防凝露）的机会。 我们在这：RC 中间继电器（含小型可拔插型）、THC 温湿度控制器、RVS 双电源切换继电器。
  • GGD / GCS / GCK / MNS：都是低压柜（0.4kV）型号——GGD 固定面板式（最普及）；GCS/GCK/MNS 抽屉柜（每个回路做成小抽屉，内装断路器+接触器+中间继电器+时间继电器）。低压成套厂的地盘，量大但选型权常在终端/设计院。 我们在这：RC 中间继电器、RT 时间继电器、FA 信号报警器、THC 温湿度控制器。
  • MCC / 动力中心（电机控制中心）：0.4kV 集中管理几十台电机的抽屉柜列，每台电机一个抽屉（断路器+接触器+热继电器+中间继电器+时间继电器）。电机类工厂、水厂、电厂辅机都是 MCC，是中间/时间继电器用量最大的柜型之一。 我们在这：RC 中间继电器（顺序启动/星三角/互锁）、RT 时间继电器（延时/循环）、THC 柜内防凝露、FA 信号报警器（电机故障汇总）。
  • 配电柜 vs 配电箱：大个立地上的叫柜，小个挂墙上的叫箱（照明箱 AL、动力箱 AP）。箱子里也有继电器，量小。
  • 动力柜（AP）/ 照明箱（AL）：给电机/照明配电的末端柜，接触器+中间继电器+时间继电器的用量大户（电机顺序启动、星三角切换、互锁）。
  • 进线柜 / 出线柜（馈线柜）：电源进来的柜 / 电分出去的柜。"馈线"= 分出去的线路。
  • 计量柜 / PT柜：装电表计量的柜 / 装电压互感器的柜。PT柜里的电压继电器（RMY）监视母线电压（欠压/过压告警）、电量变送器（TE）把计量数据送后台——这是你变送器和电压继电器的经典应用位。 我们在这：RMY 电压继电器（母线电压监视）、TE 电量变送器（遥测上传）。
  • 联络柜（母联柜）：把两段母线连起来的柜。两路电源互为备用时由它切换——"备自投（BZT）"= 备用电源自动投入，就是母联柜自动合闸的逻辑；并网/备自投合闸前要"检同期"，同步检查继电器（RMY-T）就是干这个的；双电源切换继电器（RVS）是执行元件。 我们在这：RMY-T 同步检查继电器、RVS 电源切换继电器、RC 中间继电器（出口回路）。
  • 无功补偿柜（电容柜）：装电容器组提高功率因数（避免被电网罚款），电容器投切回路的延时/联锁用时间继电器、中间继电器。我们在这：RT 时间继电器（投切延时）、RC 中间继电器（联锁）、THC 柜内温控（电容柜发热）。
  • 变频柜 / 软启动柜：装变频器或软启动器的柜子，控制电机调速/平滑启动。变频器是电磁干扰源，旁边继电器容易误动——这是 RAI 抗干扰继电器的招牌场景。 我们在这：RAI/RAI-V 抗干扰继电器（变频器旁）、THC 温湿度控制器（变频器发热大要散热/防凝露）、YDSP 开关电源（给控制板供电）。
  • 直流屏（直流电源柜 / 直流系统）：变电站/配电室的"心脏起搏器"——柜内蓄电池组 + 充电模块，平时给全站二次设备供电，交流电全停时靠电池撑住——保护和断路器跳合闸一刻都离不开它。客户必查、验收必看的核心柜：
    • 合母 / 控母（HM / KM）：合闸母线（电压高，如 DC220V，给合闸线圈瞬间大电流）；控制母线（给保护、仪表、继电器的小电流电源）。合母经硅链（降压硅堆）降到控母等级。客户说"控母电压监视"= 你电压继电器（RMY）的活。
    • 浮充 / 均充：平时小电流"浮充"养电池；定期大电流"均充"补足。直流屏维护的高频词。
    • 绝缘监测：直流系统有一极对地绝缘坏了会误跳闸——绝缘监测装置监视正/负母线对地绝缘，配套绝缘监测继电器。
    • 电池巡检 / 电压监视：逐节监视电池电压+母线电压，越限报警——电压继电器 + 信号报警器（FA）输出光字/音响报警。
    • 闪光回路：事故时指示灯闪烁提示值班员，老站用闪光继电器。
    • 一句话：直流屏里中间继电器、电压继电器、双位置、信号报警器大量使用，柜内直流供电还用到开关电源（YDSP）和冗余模块（DPM）——听到客户做直流屏/直流电源，直接报全系列。
    • 我们在这（直流屏全家桶）：RMY 电压继电器（合母/控母电压监视）、RDP 双位置继电器（位置指示）、FA 信号报警器（故障汇总报警）、YDSP 开关电源 + DPM 冗余模块（柜内供电）、绝缘监测配套继电器。
  • 一体化电源柜（智能一体化电源系统）：新建变电站的主流配置——把直流屏、UPS、通信电源、逆变电源合成一个柜、共享一组蓄电池。客户说"做一体化电源"= 还是直流屏那套元件，只是柜子合并了。我们在这：同直流屏全系列（RMY/RDP/FA/YDSP/DPM），外加 UPS 相关变送与切换。
  • 通信屏 / 远动屏：装通信管理机、四遥设备的屏（把现场信号送电网后台）。"温度/电流要上传"= 变送器（TT/TE）挂到这面屏的机会。 我们在这：TT 温度变送器、TE 电量变送器、TTH 温湿度变送器（RS485 直挂通信管理机）。
  • DTU / FTU 站所终端柜（配网自动化柜）：装配网自动化终端的户外/户内柜——DTU（站所终端，管整个配电室）、FTU（馈线终端，管一条线路）。做配网自动化的客户=变送器+开关电源的稳定客户。 我们在这：TE 电量变送器（电压/电流采集）、RS485 通信配套、YDSP 开关电源、THC 户外柜防凝露。
  • UPS / EPS 屏：交流不间断 / 应急电源柜，机房和楼宇标配，内含控制回路。
  • 箱变（箱式变电站）：变压器+高压柜+低压柜整套装进一个铁箱，工厂预装、现场吊装。欧式（大铁房子）/ 美式（变压器本体+外挂）两种。箱变里的干变同样要装温控器（DTC/TC）——干变厂接箱变订单 = 温控器跟着走。 我们在这：DTC/TC 干变温控器、RVS 双电源切换（箱变常有双回路）、RL-TBJ 防跳、RDP 双位置、THC 箱内防凝露。
  • 端子箱 / 汇控柜：户外设备旁的小柜子。端子箱=电缆中转接线；汇控柜=GIS/户外断路器旁的"大脑"，汇集本间隔全部二次回路（跳合闸、信号、闭锁、加热驱潮）。汇控柜里防跳、双位置、非全相、SF6闭锁继电器、温湿度控制器（防凝露）全套都装——断路器厂/GIS厂/集成商是 RN 系列的客户。 我们在这：RL-TBJ 防跳、RDP 双位置、RN-FB 非全相、RN-FT 防跳+SF6闭锁、THC 驱潮加热、YDSP 柜内供电——汇控柜=RN 系列全家福。
  • GIS（气体绝缘全封闭组合电器）：把断路器、隔离开关、母线全封进金属筒充 SF6 气体，占地小、可靠性高——城市变电站和新能源升压站主流。每个 GIS 间隔配一台汇控柜=每个间隔都是你的继电器容量。 我们在这：同汇控柜全套（RN 系列是核心，SF6 低气压监视就是 RN-FT 的招牌功能）。

4.3 断路器与操作机构（防跳/双位置/非全相的"家"）

  • 断路器本体 vs 操作机构：本体管"灭弧+分合电流"；机构是"肌肉"——弹簧储能、分合闸线圈、辅助开关都在机构箱里。操作机构厂 = 你的核心目标客户。
  • 弹簧操作机构 / 永磁机构：两种主流。弹簧机构 = 电机拉紧弹簧储能、释放完成分合闸。
  • 储能：合闸弹簧上紧的过程。客户说"储能回路"= 控制储能电机的二次回路（储能电机控制用中间继电器+时间继电器）。
  • 合闸线圈（YC）/ 分闸线圈（YT）：通电即动作的"电磁扳机"。你的继电器控制的最终对象就是这两个线圈——客户说"防跳回路"，防的就是合闸信号粘住导致合闸线圈反复受电、断路器在故障上反复分合（"跳跃"），几秒就烧机构。
  • 防跳继电器（RL-TBJ）：装在断路器控制回路，标准配置——听到"防跳"两个字=掏 RL-TBJ。
  • 三相不一致 / 非全相（RN-FB）：220kV 及以上大断路器分相操作（A/B/C 三相各自一个机构），故障时可能只跳开一相——非全相运行对电网危害大，需延时三跳。RN-FB 装在汇控柜/端子箱里监视三相位置并延时跳三相。
  • SF6 低气压闭锁（RN-FT 的功能之一）：SF6 气压低于闭锁值 = 灭弧能力不足，此时闭锁分合闸（强行操作=放电事故）。RN-FT = 防跳 + 低气压闭锁二合一，一个继电器顶两个功能位。
  • 行程开关 / 辅助开关（位置触点）：机构上随断路器位置联动的机械触点，给二次回路发"已合/已分"信号——双位置继电器（RDP）和跳合位监视继电器（RL-THW）就是用来监视和保持这些位置的。
  • 我们在这（断路器操作机构全家桶）：RL-TBJ 防跳继电器、RDP 双位置继电器、RL-THW 跳合位监视、RL-CBS 跳合闸回路监视、RL-PSS 电源监视、RN-FB 非全相（分相机构）、RN-FT 防跳+SF6 闭锁、RL-TBJ-DW 直流操作型（直流操作机构）。

4.4 二次回路"黑话"（听懂客户讨论图纸）

  • 控制回路 / 信号回路 / 测量回路：跳合闸指令走的路 / 位置与报警上传的路 / CT/PT 信号进仪表的路。你的产品横跨三者——控制回路=继电器家族，信号回路=信号继电器/报警器，测量回路=变送器家族。
  • TWJ / HWJ（跳闸位置继电器 / 合闸位置继电器）：监视断路器在分位还是合位的继电器——双位置继电器（RDP）/ 跳合位监视继电器（RL-THW）的典型应用位。客户说"TWJ 不励磁了"= 跳位监视回路故障。
  • 屏顶小母线：一排屏柜顶上贯穿的共用电源铜排（控制电源、信号电源、闪光母线等），每面屏从屏顶取电。
  • 端子排 / 端子：二次接线的中转站，继电器经端子接入柜内回路。客户说"端子排不够用/太挤"= 推可拔插式省端子的机会。
  • 光字牌：柜门上写着"断路器跳闸""SF6 报警""控制回路断线"的发光窗，由信号报警器（FA）驱动——客户提"光字牌""事故音响""警铃"= FA 的活。
  • 中央信号 / 事故总信号：全站报警的汇总（警铃+光字+送后台），是信号报警器的主战场。
  • 合闸红灯 / 跳闸绿灯：柜面指示灯，红=合位、绿=分位，串在位置继电器触点回路里。
  • 控制回路断线（控制回路断线告警）：TWJ 和 HWJ 都不励磁 = 回路失电——电网最常见的告警之一，背后就是位置监视继电器（RL-THW）的应用逻辑。
  • 联锁 / 闭锁：防止误操作的逻辑关联（如隔离开关未分不许合接地刀）；闭锁=强制禁止。闭锁回路里继电器的用法（如 SF6 闭锁、低气压闭锁）你要能接上话。
  • 我们在这（二次回路）：RDP 双位置继电器（TWJ/HWJ 位置监视）、RL-THW 跳合位监视（控制回路断线告警）、FA 信号报警器（光字牌/中央信号）、RC 中间继电器（出口/信号放大回路）。

4.5 温控与测温场景（DTC/TC/TCC/TK 的"家"）

  • PT100 埋件：干变三相高压绕组里预埋的铂电阻测温点（每相 1~2 只，高端的低压绕组/铁芯也埋），引线到温控器。
  • 冷却风机（横流风机）：干变底部或侧面的散热风扇。温控器分级动作：预警（一级温度告警）→ 启动风机（二级）→ 跳闸（三级超温直接跳断路器）——这就是你向干变厂讲 DTC/TC 时的标准话术。
  • 风机报警器（TCC）：风机本体也要被监视——风机停转/断线就报警。干变配了风机却没配风机监视 = 客户的盲区，主动提。
  • 第四路测温：DTC 支持三相绕组+第四路（环境或铁芯）——高配干变测点多，报价时问清埋了几只电阻。
  • 超温跳闸 / 温度远传：绕组到跳闸值输出跳闸；同时把温度变送成 4-20mA 送后台（TT 温度变送器的活，或选带模拟量输出的 DTC）。
  • 热电偶采集器（TK）：电厂、工业现场几百上千度的高温测点用热电偶，四路采集、四路超温告警——别拿 PT100 的产品去接热电偶，测温元件分场景。
  • AN / AF（自冷 / 风冷）：空气自冷 / 强迫风冷。自冷干变也建议装温控器做监视（只监视不启风机）——这是干变厂做自冷款时的隐性需求，别漏。
  • 我们在这（干变测温场景）：DTC/TC 干变温控器（三相+第四路测温、启风机、超温跳闸）、TCC 风机报警器（风机断线监视）、TT 温度变送器（温度 4-20mA 远传）、TK 热电偶采集器（高温测点）。

4.6 温湿度、凝露与挡位场景（THC/TTH/TG 的"家"）

  • 凝露 / 驱潮：柜子昼夜温差会在柜内结露（凝露）→ 爬电、闪络事故。温湿度控制器（THC）检测到凝露风险自动投切加热器（驱潮）——开关柜、端子箱、汇控柜内标配。听到客户说"凝露""驱潮""柜内加热"= THC 的机会。
  • 温湿度上传：客户要把柜内温湿度传后台/平台——温湿度变送器（TTH）输出 4-20mA 或 RS485，和 THC（本地控制）是两回事：一个管"上传看得见"，一个管"自动投加热"，很多场景两个都要。
  • 有载调压 / 挡位：变压器带有载分接开关（OLTC）可以不停电调压（调输出电压挡位），挡位信号要传给后台/挡位表——挡位变送器（TG）就是把挡位转成 4-20mA 输出的（用有载调压变的电厂、变电站是它的客户）。
  • 我们在这（温湿度/挡位场景）：THC 温湿度控制器（本地检测凝露自动投加热器驱潮）、TTH 温湿度变送器（柜内温湿度 4-20mA/RS485 上传后台）、TG 挡位变送器（有载调压挡位远传）。记住分工：THC 管"本地自动动作"，TTH 管"上传看得见"，很多柜子两个都要。

4.7 电源与变压器场景（YDSP/DPM/XF 的"家"）

  • 柜内直流供电：柜子里一堆继电器、变送器、温控器都要直流电吃饭——开关电源（YDSP）就是把柜内交流变成稳定直流的"食堂"。交流 100~240V 输入，输出 110VDC/220VDC，120W~1000W 四档。卖继电器时顺手问一句"柜内直流电源用谁的"——元件越多电源功率越大，捆绑机会。
  • 冗余供电：重要负载（保护、监控、通信）不能断电——两台开关电源 + 二极管冗余模块（DPM）并联，一台故障另一台无缝顶上。客户说"供电冗余""N+1""重要负载不能掉电"= DPM 的机会。
  • 控制变压器（XF）：380V 转 100V 等电压等级转换，负载阻抗 ≥50K、精度 1%——进口设备、特殊电压等级仪表、老系统改造会点名要。单相三相可选。
  • 双电源切换：箱变、户外柜、通信站点常有两路进线——双交流/双直流电源切换继电器（RVS/RVS-DC）自动切换，AC1 失电秒切 AC2、恢复自动切回。客户说"双回路供电""两路进线自动切"= RVS 系列。
  • 我们在这（电源场景）：YDSP 开关电源（柜内交变直供电）、DPM 二极管冗余模块（双电源并联不断电）、XF 控制变压器（380V 转 100V 等电压转换）、RVS/RVS-DC/RMS 双电源切换继电器。

4.8 新能源场景（光伏/风电/储能/充电桩——现在最肥的客户群）

  • 光伏电站（一步步看每个设备里有什么）：
    • 汇流箱：把若干串光伏板电流汇成一路，内含熔断器、断路器、防反二极管、通信模块——我们在这：THC 温湿度控制器（户外箱防凝露）、RS485 通信配套、小型中间继电器 RC。
    • 逆变器：直流变交流，IGBT 功率器件发热大、控制板娇贵——我们在这：温度变送器 TT（测 IGBT/进线温度）、THC 柜内温控、YDSP 开关电源（给控制板供电）。
    • 箱变：升压到 35kV——我们在这：DTC 干变温控器、RL-TBJ 防跳、RDP 双位置、THC、YDSP。
    • 升压站：全站直流屏 + 保护屏——我们在这：直流屏全家桶（RMY/RDP/FA/YDSP/DPM）。
  • 风电场：机舱（变桨、偏航、主控柜——我们在这：控制柜 RC 中间继电器、TT 温度变送器测齿轮箱/发电机温度、THC 防凝露）；塔筒（电缆、升降机控制、环境监测——我们在这：TTH 温湿度变送器、THC 驱潮）；箱变 + 升压站（同光伏）。
  • 储能电站：PCS 舱（变流器+控制柜——我们在这：控制柜 RC 继电器、温度变送器、YDSP 开关电源）；电池舱（电池簇 + BMS，怕热怕湿怕烟雾——我们在这：TTH 温湿度变送器、THC 驱潮、FA 信号报警器（温度/烟雾告警联动））；升压站/箱变（同上）。
  • 充电桩 / 充电站：交流桩（小功率，控制板+计量——我们在这：TE 电量变送器（计量）、YDSP）；直流快充桩（整流模块+控制板，模块发热大——我们在这：TT 温度变送器（模块温度）、YDSP 辅助电源、THC）；充电场站箱变（同上）。客户做充电桩/充电堆=电源类+温度类产品的稳定客户。
  • 氢能/制氢（新赛道，提前占位）：电解槽+整流电源+控制柜——我们在这：整流柜温控、YDSP、变送器。目前量小，但客户跑起来后先入为主。
  • 新能源一句话总结：这些场景本质都是"柜子+测温+供电+通信"的组合，我们的五大类产品（继电器/变送器/温控/信号报警/电源）在每一个环节都有位置——见到新能源集成商，按"柜内供电 YDSP + 测温 TT/TTH + 防凝露 THC + 控制继电器 RC"一整套报。

4.9 工业与楼宇场景（传统行业的基本盘）

  • 消防泵控制柜 / 排烟风机控制柜：消防泵、排烟风机要求双电源+自动启动（顺序启动/互锁）——我们在这：RVS 双电源切换、RT 时间继电器（顺序启动）、RC 中间继电器（互锁）、FA 信号报警器（消防联动信号输出）。注意：消防类产品部分要消防认证（CCCF），报价前先确认客户要什么证。
  • 电梯控制柜：曳引机控制+门机控制+平层——我们在这：RC 中间继电器、RT 时间继电器、双电源切换 RVS（电梯两路电）。电梯厂继电器用量大且常年稳定。
  • 起重 / 行车 / 港口机械：起升、行走、变幅机构控制——我们在这：RC 中间继电器、RT 时间继电器、RAI 抗干扰继电器（大电流起吊瞬间干扰大，普通继电器容易误动）。
  • 泵站 / 水处理：水泵控制柜——我们在这：RT 时间继电器（水泵顺序启动）、RC 中间继电器、TE 电量变送器（电流/压力上传）、THC 柜内防凝露（泵房潮湿）。
  • 数据中心 / 机房：UPS + 列头柜 + 配电柜——我们在这：TE 电量变送器（电能质量监测）、YDSP 开关电源、FA 信号报警器、TTH 温湿度变送器（机房环境）。
  • 通信基站 / 一体化户外机柜：5G 基站、户外通信柜——我们在这：THC 温湿度控制器（户外柜必凝露，标配加热）、TTH 温湿度变送器、YDSP 开关电源、RVS 双电源切换（基站常有两路市电）。
  • 矿山井下：防爆配电设备、强干扰环境——我们在这：RAI 抗干扰继电器、THC 防凝露（井下潮湿）。井下还有防爆认证要求，先问客户要什么证。
  • 轨道交通：牵引变电所直流开关柜、环控电控柜——我们在这：RMY 电压继电器（直流母线监视）、TE 直流变送器、RDP 双位置、RC 中间继电器。轨交要 CRCC 认证（见资质章），有证才有入场券。
  • 船舶 / 港口：船用配电板、岸电设备——我们在这：船用型继电器/变送器。船用要 CCS 认证（见资质章）。
  • 电厂（火电/燃机）辅机系统：DCS 控制柜 + 辅机 MCC——我们在这：TK 热电偶采集器（高温测点）、TT 温度变送器、RC 中间继电器、FA 信号报警器。电厂是 TK/热电偶类产品的第一大客户群。

五制造模式：OEM / ODM / OBM / JDM贴牌与代工全家桶

这是客户问得越来越多的一组词，尤其客户想"做自己的牌子"或者想把你的产品装进他家设备里转卖时，一定会蹦出来。四个字母之差，含义天差地别。

5.1 OEM（Original Equipment Manufacturer，贴牌代工）

  • 大白话：客户出品牌、出技术要求（图纸/规格书），你只负责按他的要求生产，产品打他的牌子。
  • 例子：某干变厂要求你按他们的规格生产温控器，丝印（产品上的字）打他们厂的 logo，出厂后当"他们家的温控器"卖给下游客。
  • 特点：技术规格是客户定的，你赚的是制造加工费；客户掌握"设计权"。
  • 对你意味着什么：客户问"你们能做 OEM 吗？"= 给你贴牌订单。接 OEM 单通常要谈三件事：最小起订量（MOQ）、丝印/包装定制费、是否签保密协议（NDA）。我们做 OEM 是纯赚产能的钱，但要防客户拿你的方案去比价。

5.2 ODM（Original Design Manufacturer，原创设计制造）

  • 大白话：你出产品设计（现成产品线），客户挑中后贴他的牌子卖。
  • 例子：客户看中你目录里的 DTC 温控器，不改设计，只要求打他的 logo——这就是 ODM。
  • 特点：产品是你的，品牌是他的。对你意味着什么：这是利润最好的贴牌模式——公司已有完整产品线，接 ODM 单几乎零开发成本，卖的还是你的标准品。

5.3 OBM（Original Brand Manufacturer，自主品牌）

  • 大白话：自己设计 + 自己的品牌 + 自己销售，从头到尾都是自己家的。公司现在走的路就是 OBM。
  • 对你意味着什么：向客户强调"我们是自主品牌制造厂，不是贸易商"——贸易商（只倒手不生产）在客户眼里加分低，OBM 工厂加分高。反问客户"贵司这个产品是自研还是贴牌的"，能快速摸清对方在产业链的位置。

5.4 JDM（Joint Design Manufacturing，联合设计制造）

  • 大白话：双方一起出人出技术，共同开发一款定制产品，产权/供货按合同谈。大客户提定制需求时常走这个模式。
  • 对你意味着什么：客户说"我们想联合开发一款 XX"= 大机会也大投入，先谈清楚：模具费谁出、专利归谁、是否独家供货。

5.5 一句话区分口诀（先背这个）

OEM = 你照他的方案做，贴他的牌；

ODM = 你照自己的方案做，贴他的牌；

OBM = 你照自己的方案做，卖自己的牌。

客户嘴里"代工""贴牌""定牌生产"通常泛指 OEM/ODM，追问一句"规格是你们定还是我们定"就能分清。

5.6 相关词

  • 白牌 / 中性包装：产品不打任何品牌（或包装无品牌），客户买回去自己贴。常用于客户做自己的品牌起步期——是切入 ODM 的前奏。
  • NDA（保密协议）：OEM/JDM 前客户基本都要求签。正常流程，不用怕。
  • 贸易商 / 代理商 / 授权代理：只卖不造的中间商。客户问"你是厂家还是贸易商"，答：厂家（OBM 自主品牌+自有工厂）。

六BOM 深度解析打进客户心脏的那张清单

BOM 是销售元件的人最值得搞懂的一个词：你的型号写进 BOM 的那天，基本等于锁定了一个随客户产量滚动的长期订单。

6.1 BOM 是什么

  • BOM（Bill of Materials，物料清单）：一台产品所有零件的完整清单——外壳、螺丝、线材、继电器、温控器、开关电源……每一行 = 物料号 + 名称规格 + 数量 + 供应商/品牌。
  • 客户的研发部（不是采购部）维护 BOM；它存在客户的 ERP/PLM 系统里；生产计划、采购下单、成本核算全部跟着 BOM 自动走。
  • 打个比方：菜谱之于厨房 = BOM 之于工厂。菜谱里写了要用什么牌子的酱油，厨师（采购）就买什么牌子——换酱油要厨师长（研发）签字。

6.2 BOM 的几个层级（听得懂客户内部讨论）

  • EBOM（设计 BOM）：研发图纸拆出来的清单，"设计上要什么"。
  • MBOM（制造 BOM）：加上工艺信息（怎么装、装到哪道工序），"生产上怎么用"。
  • 采购 BOM / 采购清单：从 MBOM 汇总出"要向供应商买什么、买多少"——你的订单源头。

6.3 A 点 / B 点（供应商点位）

  • 客户为防断供，同一物料常指定两家供应商：A 点 = 主选（份额大头），B 点 = 备份。
  • 客户说"你们是 B 点"= 平时基本不给你量，A 点断供才轮到你。
  • 你的目标永远是抢 A 点：从 B 点转 A 点，要抓的时机是 A 点出质量问题（8D/交付事故）或年降谈崩。

6.4 ECN / ECO（工程变更通知）

  • BOM 不是随便改的：改一个料号、换一个供应商，要走工程变更流程——研发发起、评审、重新验证（有时要重新送样甚至重做型式试验）。
  • 对你意味着什么（双刃剑）：
    • 坏消息：图纸定型后你很难插进去——换料要客户走一圈 ECN，谁都不想惹这个麻烦。
    • 好消息：一旦你进了 BOM，竞争对手想把你换掉同样要过 ECN 这道坎。所以客户说"图纸定型了"，你的正确动作是攻他们的"下一代产品"（新品立项时 BOM 还是敞开的）或备件渠道。

6.5 替代料 / 同等替代（OR Equivalent）

  • BOM 里某一行可能写"XX品牌 或 同等（OR equiv.）"——意味着有弹性空间。
  • 挤进"同等"名单比硬换 A 点容易得多，是替代进口件（Phoenix、UE 等）的常用通道。

6.6 从送样到进 BOM 的完整路径（背下来）

  1. 送样（免费样品 + 规格书 + 检测报告）
  2. 上机测试 / 小批量试用（客户产线验证）
  3. PPAP / 批产认可（汽车行业词，工业客户类似流程：提交全套文件证明你能稳定量产）
  4. 量产导入（MP）：研发把你的物料号写进 BOM，ECN 发布
  5. 稳定供货 → 争取份额提升（B点→A点）→ 应对年降

客户说"图纸定型了"卡在第 4 步之前；客户说"下个平台/下一代在规划"= 第 1 步的入口敞开着。

八客户在用的企业系统听懂"我们走系统"是什么意思

  • ERP（企业资源计划）：客户管订单、库存、财务、BOM 的主系统。客户说"进 ERP"= 你的报价单进入了正式采购流程，比口头询价正式得多。
  • SRM（供应商关系管理）：客户管理供应商的网上平台——注册、资质上传、报价、订单、对账都在上面。"在 SRM 注册"= 网上申请成为他们的合格供应商。
  • MES（制造执行系统）：车间生产管理。客户提"物料要扫码进 MES"→ 意味着你的产品标签/丝印要带条码或二维码，报价时确认好标签格式。
  • PLM / PDM（产品生命周期/数据管理）：图纸、BOM、技术文件的家。"料号在 PLM 里建好了"= 你已正式进入 BOM 体系。
  • CRM：销售用的客户管理系统。你自己的公司也可能用。
  • WMS：仓库管理系统。
  • OA：办公自动化（内部审批流）。客户说"流程在 OA 里走"= 内部审批中，催也没用，等。
  • 电子采购平台 / 电子商城：国网商城、客户自建商城等。"这单走商城"= 价格流程全部线上化，先完成平台入驻。

九采购流程与商务名词决定你单子怎么成

9.1 询价与下单链路（一图记牢）

PR（采购申请，客户内部发起）→ RFQ（询价单，发给你）→ 报价 → 询比价/招标 → PO（采购订单）→ 合同 → 交货 → 对账 → 开票 → 回款

  • RFQ（Request For Quotation，询价单）：客户正式发来的询价文件，常带规格书/图纸。收到 RFQ ≠ 拿单，只是入场券；但客户发 RFQ 给你而不是别人，说明你已经进了短名单。
  • PO（Purchase Order，采购订单）：客户下的正式订单。收到 PO 才是真正的成交信号——口头答应/邮件意向都不算。PO 上的价格、数量、交期、账期是结算依据。
  • 交期（Lead Time，交付周期）：下单到交货的时间。客户常问"交期多久？"——交期快是小厂打大厂的经典武器，尽量备常用规格半成品。
  • MOQ（最小起订量）：接单的最小数量。做 OEM/定制时你要报 MOQ（比如定制丝印 MOQ 500 台），否则客户要 50 台你也得开产线。

9.2 采购方式

  • 询比价：客户发询价函给几家供应商，比完价直接定——门槛最低的采购方式，你的主攻模式。
  • 招标 / 议标 / 单一来源：公开招标（走流程文件）；议标（小范围谈）；单一来源（指定一家）。你找"不走招标的客户"，就是找能询比价/直采的。
  • 集采：集团层面集中采购（如国网集采、许继集团集采）。量大但流程重、账期长。你公司现有的许继/平高/西电合作就是集采模式。
  • 直采/自采：事业部/车间自己决定买谁的（不走集团流程）——最好切入的口子。

9.3 供应商准入

  • 合格供应商 / 入围：进入客户"合格供应商名录"（也叫短名单），之后才能被询价。很多客户第一单不是卖出来的，是"注册+审厂+送样"通过后自动来的。
  • 送样 / 打样 / 样件：免费提供样品给客户测试。"送样通过"是进图纸的前奏。
  • 审厂 / 验厂：客户来你的工厂实地检查产能质量体系（SQE 带队，查体系文件、产线、检测设备）。客户提出审厂=认真想合作了，是好消息。
  • 供应商年度审核 / 年度评级：大客户每年复审一次，评级（A/B/C 或优秀/合格/整改）。C 级/整改 = 份额会被砍，也是抢 A 点的时机窗口。

9.4 采购条款类

  • 框架协议：先谈好一年的价格和量，按需分批下单——续单最容易的形式。
  • 长协（长期协议）：多年度的框架协议，比一年期更稳。
  • 年降（年度降价）：大客户对供应商的年度降价要求，常见 3%~5%。谈判筹码：用年降换份额提升、用年降换 A 点。 听到"年降5个点"别直接答应——要拿到量承诺再让。
  • 寄售 / VMI（供应商管理库存）：你先把货放到客户仓库，客户用了才结算。压的是你的资金和库存风险，小客户别轻易答应；大客户可换长期锁定的量。
  • JIT（准时制交付）：客户要你按他的生产节奏小批量高频送货。接 JIT 前确认自己备货能力。
  • 安全库存 / 备货：客户说"先备点货"——让你承担库存。要谈：备多久、滞销料谁消化。
  • 分批交货：一个 PO 分几批发，常见于项目型订单。
  • 评标 / 中标候选人公示：招标流程术语。"中标候选人"=拟成交但还没最终定。

十财务、发票与回款别在钱上露怯

技术谈得再好，最后栽在发票和账期上就全白干。这节是防身用的。

报价前必确认 6 件事（少问一件，后面就有一个坑）

① 含税还是未税——13% 专票差 13 个点，直接吃掉毛利（见 10.1）；② 运费谁出——含运还是到付，报价单写死，别"到时候再说"；③ 账期 / 预付——新客户尽量款到发货或预付 30%+（见 10.2）；④ 开什么票、抬头开谁——专票普票、三流一致（见 10.1）；⑤ 质保与质保金——质保几年、押多少比例、何时释放（见 10.2）；⑥ 货期——客户要的日期能否满足、超期怎么算，别拍脑袋承诺。

10.1 发票

  • 增值税专用发票（专票）：13% 税率的可抵扣发票，一般纳税人客户必须要这张才能抵扣进项税。
  • 增值税普通发票（普票）：不能抵扣。小规模纳税人客户可能只要普票。
  • 客户说"发票要 13 个点的" = 要 13% 增值税专票。报价前必问含税与否，否则 13 个点直接吃掉你的毛利。
  • 含税价 / 未税价（不含税）：报价单一定要写清楚。同样报 100：含税 100 = 实际货款 88.5，未税 100 = 客户实付 113——差距巨大，报价前必确认。
  • 三流一致：合同流、货物流、发票流必须一致（合同签 A 公司、货发给 B 公司、发票开 C 公司 = 违规）。客户要"发票开到我们关联公司"时务必谨慎，坚持三流一致。

10.2 付款方式

  • 账期：先货后款的天数（30/60/90 天账期）。对你这种跑新客户的：新客户尽量款到发货或预付。
  • 预付款（预付）：下单先付一部分（30%~50%），新客户最安全的开局。
  • 款到发货（现款现货）：最保守也最安全。
  • 承兑汇票（银承 / 商承）：
    • 银行承兑：银行担保到期兑付，基本安全但有期限（3~6 个月常见），急用钱要贴现（贴现 = 提前取钱，银行扣利息）。
    • 商业承兑：只靠企业信用担保——房企、资金紧张客户的商承约等于白条，能拒就拒。
    • 客户问"走承兑可以吗"：可以接银承，但问清期限、计入账期。
  • 质保金（质保金条款）：合同总额的 5%~10% 押 1~2 年，质保期满无质量问题才付。项目型订单的标配，报价时要把它算进现金流。
  • 履约保证金 / 投标保证金：投标时交的押金。投标保证金法定上限为项目预算 2%，未中标必须退还；履约保证金一般 ≤ 合同额 10%，常用保函代替。
  • 保函（银行保函）：让银行替你担保，交少量保证金就能开出，代替现金保证金——投标多时必备工具。
  • 挂账 / 应付账款：客户收货入账后进入"挂账"状态，等账期到点付款。客户说"已经挂账了"= 货他们认了，钱在排队——记录账期起算日，到期主动对账催收。
  • 对账：双方核对应收应付明细，一般季度或半年度一次。对账单是催款和追债的基础证据。

十一质量术语SQE 对话防身

  • SQE（Supplier Quality Engineer，供应商质量工程师）：客户里专门管供应商质量的人。审厂是他带队、质量问题是他追你、8D 报告是他要——技术+质量线上的关键人物，和他搞好关系能提前知道很多内部信息。
  • IQC / IPQC / OQC：来料检验 / 制程检验 / 出货检验——工厂质检三道关。客户审厂必查你的检验记录。
  • 型式试验 / 出厂试验：型式试验=第三方权威机构对产品做的全套认证试验（贵、周期长、一般做一次）；出厂试验=每台出厂前的例行检测。客户问"有没有型式试验报告"= 问你产品有没有权威背书。
  • 检测报告 / 出厂检测报告：每批货随附的检测数据。监理和业主常查。
  • 8D 报告：客户投诉质量问题后要求你提交的"8 步整改报告"（问题描述→临时措施→根因→永久措施→效果验证→预防→总结）。写 8D 是流程，闭环它才能保住供应商资格；客户要 8D 说明还想留着你，真不想要你直接降级了。
  • PPM（百万分之不良率）：质量水平指标。元件行业不良几百 PPM 算正常，几十 PPM 优秀。
  • RMA（Return Merchandise Authorization，退货授权）：客户退货前要先申请授权号。客户提 RMA = 走正式退换流程。
  • MTBF（平均无故障时间）：可靠性指标，小时数越大越可靠。继电器常标机械寿命/电寿命（如 10⁷ 次机械、10⁵ 次电气）——客户问寿命报这两个数。
  • AQL（可接受质量水平）：抽检判定标准，客户来料抽检按它执行。
  • 开箱合格率 / 上机直通率：客户拆箱即不良 / 上产线一次通过的比例。这两个数字难看，IQC 直接退货。
  • 质保期 / 保修期：一般 12~24 个月。质保期起算点常谈：发货日起 or 到货签收日起——差几个月，务必写进合同。

十二资质与标准你的"敲门砖"体系

  • CCC认证：中国强制性产品认证。低压元器件的基本证。你有。
  • CQC认证：中国质量认证中心的自愿性认证。很多招标文件写"CCC 或 CQC"——没有 CCC 的品类靠它补位。
  • 国网/南网入网：进入国家电网/南方电网采购体系的资质门槛。你有——这是对电网侧客户最强的卖点。
  • 型式试验报告：国家级检测机构（如国网电科院、西高所）出具。客户认可度最高的单件资质。
  • IEC / GB / DL：国际电工委员会标准 / 国标 / 电力行业标准。客户说"按GB/T XXXX做"，指的是产品依据的标准号。
  • CE / UL / TÜV / CB：欧盟 / 美国（Underwriters Lab，安规严）/ 德国（TÜV，欧洲客户认）/ 国际互认体系认证。出海客户或外资客户会点名要——看到客户做出口，主动问"需要 CE 吗"。你有 CCC、CE、CB。
  • RoHS：有害物质限制（欧盟环保指令），电子电器出口欧盟必备。
  • CCS / CRCC：中国船级社 / 铁路产品认证。做船海客户要CCS；做轨交客户要CRCC——这两张证是你下一阶段的敲门砖。
  • EMC：电磁兼容。抗干扰继电器（RAI）的核心卖点就是 EMC 指标。
  • CNAS 实验室：国家认可委认可的实验室（自实验室出报告带公信力）。客户问"你们实验室是 CNAS 吗"= 问你自检报告的权威性。
  • ISO9001 / ISO14001 / ISO45001：质量/环境/职业健康安全管理体系。审厂第一道查的就是这三张，年审记录要齐。你有 ISO9001、ISO14001。
  • 专精特新 / 小巨人 / 瞪羚企业：工信部/地方给成长型企业的官方评级——看到目标客户有这些头衔=官方盖章的优质成长客户。
  • 国家高新技术企业：科技部认定的技术型企业资质。你有——招投标加分项，见客户自我介绍时用。

十三招投标全流程看懂客户的"走流程"

13.1 完整时间线（从公告到回款）

招标公告发布 → 购买/下载标书 → 制作投标文件 → 递交投标 → 开标 → 评标 → 中标候选人公示（≥3天）→ 中标通知书 → 签合同 → 履约 → 验收 → 结算（扣质保金）

  • 招标控制价 / 拦标价：招标方公布的预算上限，报价超过直接废标。拿到标书第一件事就是找这个数。
  • 技术标 / 商务标：投标文件两部分——技术方案（参数、业绩、资质）+ 商务报价。常分两信封，技术标先评，不过关商务标不拆（俗称"技术废标"）。
  • 最低价中标 / 综合评分法：两种评标规则。最低价=纯拼价格；综合评分=价格+技术+业绩+服务加权打分（资质和业绩在综合评分法里能换回价格劣势——你的许继/西电供货记录就是打分项）。
  • 废标：投标文件不合规矩直接出局（资质缺、装订错、迟交、超控制价）。细节杀手，投标文件必须专人复核。
  • 围标 / 串标：几家串通围住价格——违法，别碰。客户暗示"找两家陪标"，直接拒绝。
  • 联合体投标：两家组队一起投（如你 + 成套厂）。
  • 授权委托书 / 法人授权：投标代表要带的法律文件。
  • 中标候选人公示：第一名的"预备"状态，3 天内没人质疑才算真中标。
  • 中标通知书：正式成交确认，之后才签合同。"我们中了"要等这张纸才算数。

十五常见异议与应对客户说不，你怎么接

客户说"不"不一定是不想买，往往是没听明白或没看到价值。每句应对都按"接住情绪 → 给事实 → 给下一步"三步走。

客户说真实心理你怎么接
"太贵了"想要更低价，或没看到价值先问"您是和哪个品牌比？"——拆开对比参数与寿命；再给总成本账（单价×用量×年用量）；最后给台阶：量起来可以谈年降
"你们是国产小厂，质量行吗"怕担责、怕不稳定不辩解，直接摆事实：国家高新技术企业、CCC/CE/CB、型式试验报告、许继/平高/西电供货记录；主动提出送样+上机测试，让产品自己说话
"我们一直用进口的（Phoenix/UE）"习惯、怕换出问题承认进口的优点，再给"同等替代"方案：参数对比表逐项对照，先小批量试用，不行不勉强——用降风险方式降低换供应商的心理门槛
"图纸定型了"不想折腾 ECN不硬推，转攻下一代/新平台立项，或备件渠道
"先拿别人样品比比"还没信任你主动送样+参数对比表+已供货客户名单，把"比"变成"按你的标准比"
"现在没预算 / 再说吧"时机不对或没需求不逼单，登记需求、记下他的立项/采购节奏，按节点跟进
"我们和别家合作很久了"有稳定供应商求做 B 点/备份，等 A 点出问题或年降谈崩的窗口
"这个东西我们自己能做"想自己干或压价不算账，先问"你们是批量做还是自用？"——自用不如买，批量做不如找专业厂，成本、测试、认证都是门槛
"再降 5 个点就下单"试探底价不裸降：降可以，换条件——提量、预付、账期缩短、签框架，任何一条都比干降价值钱
"你先放一批货试试"想零风险试用可以，但限定数量与期限，签试用协议，试完要么转正式单要么退回

附4销售红线：别踩这 10 条踩一条白干一年

  1. 报价不写"含税/未税"——13 个点增值税直接吃掉毛利，报价单先核对（见 9.5）。
  2. 把 TT 和 TS 搞混——TT 管"温度→4-20mA"，TS 管"信号→信号"（隔离变换），报错型号等于现场翻车（见 2.2）。
  3. 商业承兑当现款收——房企、资金紧张客户的商承约等于白条，能拒就拒；银承也要问期限算账期（见 10.2）。
  4. 答应陪标 / 围标——违法，客户暗示"找两家陪标"直接拒绝，宁丢单不丢人（见 13.1）。
  5. 承诺没有的认证——客户要 CCCF / CRCC / CCS / 防爆证，先确认公司有没有再报价，没有就明说"可定制申报"（见 4.9、12）。
  6. 客户说"图纸定型"还硬推——BOM 锁死换料要走 ECN，正确动作是攻下一代产品（见 6.4）。
  7. 裸降 5 个点——降价必须换条件：提量、预付、账期缩短、签框架，任何一条都比干降值钱（见 9.4）。
  8. 客户说"走流程"还天天催——OA/招标/集采有自己的节奏，催没用还招烦，按节点跟进（见 8、14）。
  9. 问到型号后缀答不上来——"2Z 是几常开几常闭"答不上 = 专业感清零，先把 2.6 型号密码背熟。
  10. 忘带"三件套"——名片、样册、样品缺一不可；样品是让客户"摸到产品"的唯一机会（见附3）。

红线不是吓唬人，是前辈用真金白银换来的教训。拿不准的条款，宁可回来问，不要现场拍脑袋。

附5客户高频 10 问速答被问住时的标准答案 · 直接能说出口

这 10 个问题是电话、微信、见面里被问得最多的中性问题（不是"太贵了"那种拒绝）。每句都能直接说出口，说完再补一句"您看还需要什么资料，我马上发您"——把对话主动权拿回来。

客户问标准答法（可直接说）注意（别踩坑）
"你们是厂家还是贸易商？""我们是厂家，国家高新技术企业，自有品牌，工厂在本地，CCC/CE/CB 都有，ISO 9001/14001 体系，已进国网/南网采购体系。"说"厂家"要给证据：认证、产线照片、审厂邀请（见 0、12）
"都有哪些认证？""CCC、CE、CB、ISO 9001/14001；每个产品还有对应的型式试验报告，您要哪个型号我马上发您。"没说到的认证别乱承诺（CCCF/CRCC/CCS/防爆证先确认，见红线 5）
"你们做过哪些大客户？""许继、平高、西电都有供货记录，进了国网/南网体系；详细的业绩清单我整理一份给您。"只报合作事实，不吹产量规模；清单回来让公司出（见 0）
"货期多久？""常备型号很快，定制型号按确认图纸和数量排产；您把型号、数量和交货日期给我，我确认后给您准确时间。"不拍脑袋承诺天数，先确认库存再报（见 9.5）
"能免费送样吗？""可以，免费送样配合您选型测试；型号定进 BOM 之后批量价格再谈。"送样要说清数量、时限、试用协议（见 6.6、15）
"质保多久？坏了怎么办？""质保条款以合同和说明书为准，写得清清楚楚；有问题我们响应，可返厂检测，流程简单。"不自己编年限，按公司标准条款答（见 10.2）
"能开 13% 专票吗？""可以，增值税专用发票；开票抬头和税号您发我，三流一致我们全力配合。"报价前先确认含税/未税，别让 13 个点吃毛利（见 10.1）
"能不能先供货后付款？""新客户一般款到发货或预付 30%，账期可以谈；量大或签框架可以走月结。"账期决定现金流，别现场答应超长账期（见 10.2）
"你们跟 XX 品牌比怎么样？""我们按您的参数要求逐项对比给您看，送样上机测试用数据说话；先小批量试用，不满意不强求。"不贬低对手，用"同等替代"降风险（见 3、15）
"有没有现货？""常备型号有库存，特殊规格按单排产；您报型号我马上查，今天能给您准信。"报型号再答"有/没有"，别笼统说"有"（见 2.6）
