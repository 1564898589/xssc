基零基础电力扫盲完全不懂电也能看懂 · 后面所有章节的地基

这一章先不急着讲怎么销售，先把"电是怎么回事、变电站里在发生什么、图纸怎么看"补到能听懂的程度。客户说的每个型号、每个回路，背后都是一个真实的物理过程——懂了物理，型号就不是死记，你也能跟技术对上话。不用一次背完，先记住 B.1 水电类比、B.2 电的旅程、B.4 故障 0.1 秒时间线、B.6 符号表这四张，其余随时回来查。

B.1 先建立直觉：用水理解电

电的概念对应"水路"单位 / 大白话
电压 V水压（推动水流的力量）伏特 V/kV；压力越大，推得越远
电流 A水流大小（每秒流过多少水）安培 A/mA；用电器越多"水流"越大
电阻 Ω水管粗细 / 堵塞程度欧姆 Ω；管子越细越堵，水流越小
功率 W水流带动机器干活的能力瓦 W/kW；电压×电流≈功率
  • 交流 AC / 直流 DC：直流电方向不变（电池、手机、直流屏）；交流电方向周期性来回变，中国电网每秒来回 50 次 = 50Hz。
  • 为什么保护和跳合闸偏偏用直流：交流一旦停电就什么都没了；直流屏带着蓄电池，哪怕全站交流电全停，仍能靠电池把断路器跳开、把信号发出去——这就是直流屏、DC220V/DC110V 存在的根本原因，也是你听到"控母/合母"的由来。
  • 三相电 / 单相电：电网用三根相线（火线 A/B/C）送电。火线对火线 = 线电压 380V，火线对零线 = 相电压 220V（380 ≈ 220×1.732）。家里只用一火一零=220V 单相；工厂电机要三相 380V 才转得有劲。
  • 销售要点：客户嘴里的 AC220 / DC220 / DC110、三相/单相、50Hz，说的都是"给继电器线圈供什么电"——选型第一步永远是先确认线圈电压和交直流，报错规格就不能用。

B.2 电的旅程：发 → 输 → 变 → 配 → 用

发电厂（10~20kV）→ 升压站升到 110/220/500kV → 高压线路远距离输送 → 枢纽变电站逐级降压（220→110→35）→ 10kV 线路送到用户附近 → 配电室/箱变里变压器降到 0.4kV → 车间设备和墙上插座。

  • 为什么要先升高电压再远距离送：同样功率，电压越高电流越小，而线路发热损耗 = 电流²×电阻，电流小，线上白白烧掉的电就少——所以远距离必须高压送电，到用户家门口再逐级降下来。
  • 电压等级台阶，对号入座：500/220kV 跨区输电主干；110/35kV 区域与大工业；10kV 到用户门口（中压配网，开关柜、环网柜、箱变的主战场）；0.4kV 进车间（低压柜、MCC、配电箱）。
  • 发电侧 / 供电侧 / 用户侧：电厂和新能源场站是发电侧，电网是供电侧，工厂楼宇是用户侧；主网（35kV 以上）、配网（10kV 及以下）的说法见 1.6。
  • 销售要点：我们的元件集中在"10kV 及以下的配、用这一段"——客户的开关柜、直流屏、箱变、干变、新能源舱都在这里。听到一个电压等级，先在这条链上定位它在哪一环，就知道该聊什么。

B.3 一次设备全家福：强电设备各干什么

母线：汇集和分配电能的公共主干道（柜内铜排），所有进出线都挂在母线上。最容易混的是四种"开关类"一次设备，先把这张表背下来：

设备（符号）切正常负荷切短路故障核心作用
隔离开关 QS不能（禁止带负荷拉）不能停电后拉开，形成"看得见的断开点"，保证检修安全
负荷开关 QL能不能（短路靠熔断器/上级断路器）正常分合负荷，环网柜里最常见
断路器 QF能能（唯一能灭短路电弧、自动跳闸）最核心最贵，故障瞬间切掉大电流
熔断器 FU—能（熔丝熔断，一次性）过流/短路时熔丝烧断保护，断了要换
  • 三工位负荷开关：把"合闸—分闸—接地"做在一台开关上（环网柜/充气柜标配），详见 B.5，工位位置要靠继电器反馈给后台。
  • 接地开关：检修时把出线侧三相可靠接地，万一误送电直接导入大地，保护现场人员。
  • 互感器 CT / PT（销售天天碰到，务必懂）：
    • CT 电流互感器（TA）：串联在主回路，把大电流按比例变小（如 600/5 = 一次 600A 变二次 5A）送给仪表和保护。铁律：CT 二次侧严禁开路（运行中开路会感应出危险高压）。
    • PT 电压互感器（TV）：并联在母线上，把高电压变低（10kV→100V）送给测量保护。铁律：PT 二次侧严禁短路。
    • 你的变送器、保护继电器看到的电流电压，全是 CT/PT 变换后的小信号——所以客户报"600/5"，量程要按二次 5A 算，别按一次 600A 报。
  • 变压器：靠电磁感应把电压升高或降低，不改频率；干变/油变、型号怎么读见 1.5。避雷器：雷击或操作过电压时泄流，保护设备绝缘。电容器柜：补无功、提高功率因数，避免被电网罚款。
  • 销售要点：每一台一次开关的"控制、保护、位置、信号"都要二次元件来实现——断路器要防跳和位置监视，三工位负荷开关要工位指示，这就是你用量的来源。

B.4 二次系统：一次设备的"神经和大脑"（你的地盘）

  • 一次 = 骨骼肌肉，走高压大电流；二次 = 神经大脑，只走小信号，干五件事：测量、控制、保护、信号、操作电源供电。你卖的全部属于二次。
  • 继电保护到底在保护什么：电网最怕短路（相线碰一起或碰地），短路电流是正常的几十上百倍，几秒就烧毁设备。保护的使命 = 实时盯着电流电压，一旦越限，在几十毫秒内命令断路器跳闸，把故障段切掉、保住其余部分。

客户嘴里常见的保护名词：

名词在抓什么故障
过负荷 / 过流电流超额定：过负荷是慢慢超（延时告警），过流要动作跳闸
电流速断电流瞬间爆表=近处短路，不延时立刻跳（"速断"=不带延时）
过压 / 欠压 / 失压电压太高、太低、或直接没了（失压）
零序 / 接地保护三相电流本应相互抵消、向量和为 0；出现"零序"=漏电或单相接地
差动保护比较设备"进"和"出"的电流，对不上=内部故障，主变/大电机主保护
备自投 BZT主电源消失，自动把备用电源/母联合上，缩短停电
  • 两条技术路线，先分清客户走哪条（极重要）：
    • 传统 / 分立元件：用一个个电磁继电器（电流、电压、时间、中间、信号继电器）按逻辑接线搭出保护和控制，看得见、好维修——这正是我们这类分立继电器产品的主战场。
    • 微机综合保护（综保 / 微机保护）：把采集、判断和一部分出口集成进一块带芯片的装置。它主要拿走"采样 + 判断逻辑 + 部分出口"，但断路器操作回路（防跳、跳/合位监视、回路监视）、位置重动、安全硬联锁、老柜改造和冗余备份，仍常在装置外另配独立继电器——所以"用了综保"不等于一颗都不用，也不能说综保一定替代不了，哪层被集成、哪层外配以客户二次图为准（分层对照见 3.1.3，独立继电器反而更稳的场景见 3.1.4）。只做综保整机、装置外回路一点都不外配的厂不是主力目标，其余都值得顺着二次图问一圈。

故障发生后的 0.1 秒（把自家产品串成一条链，这段务必看懂）：
短路发生 → CT 把大电流变小送给保护 → 电流继电器/保护判断"越限" → 时间继电器配合选择性（先跳最近的）→ 中间继电器放大出口信号 → 断路器分闸线圈 YT 得电 → 机构分闸、灭弧 → 跳位继电器 TWJ 返回"已分"位置 → 信号继电器/FA 动作，光字牌亮、警铃响、后台收到信号。这条链上每一个箭头，背后都对应着一类我们的产品。

  • 防跳为什么是标配：万一合闸按钮卡住或接点粘连，而断路器正合在故障上，就会"跳—合—跳—合"反复跳跃，几秒烧毁合闸线圈和机构。防跳继电器 RL-TBJ 保证"一次合闸命令只合一次"，这是它成为招牌的原因。
  • 销售要点：能跟技术聊到这一层，你就不只是个报型号的销售，而是懂他回路的人——推荐型号时讲得出"它在你哪条回路上、解决什么问题"。

B.5 一台开关柜里面长什么样（以 KYN28 为例解剖）

隔室位置 / 装什么
母线室柜子顶部，主母线铜排水平贯穿，各柜并联取电
断路器手车室柜子中层，装可摇出的断路器手车（VS1 等）
电缆室柜子下方，进出线电缆、CT、接地开关、避雷器
二次仪表室（继电器室）柜顶正面一格，端子排+继电器+仪表+指示灯+操作把手——你的件就住这
  • 手车的三个位置（别和"三工位开关"搞混）：工作位置（一次插头插死、主回路接通）→ 试验位置（一次断开、二次仍连着，可在不带高压下试分合闸）→ 检修位置（手车摇出柜外，形成明显断开）。手车位置也要位置开关和指示，是双位置继电器的应用位。手车本身还分工种：断路器手车、PT（电压互感器）手车、隔离手车、计量手车、熔断器手车——可摇出的小车装什么就叫什么手车，无论哪种，二次室都要给它做位置指示和联锁。
  • 三工位开关（环网柜/充气柜里）：指负荷开关本身的 合闸—分闸—接地 三个工位，和手车三位置是两回事，别混；工位信号要上传后台，靠双/多位置继电器。
  • 二次室常见小件：操作/转换开关 SA、分合闸按钮 SB、合位红灯 HR、分位绿灯 HG、压板（连接片，用来投退某路保护）、端子排、微型断路器、防凝露加热器。
  • 五防怎么实现：机械闭锁（钥匙和联锁机构，顺序错了根本操作不动）+ 电气闭锁（靠辅助接点和继电器，条件不满足控制回路就不通）。电气闭锁回路里的触点，就是继电器的应用点。
  • 销售要点：客户带你看柜，你能按"母线室—手车室—电缆室—二次室"一路说下来，并指出二次室哪里放 RC、哪里放 RL-TBJ、哪里装 THC，专业度立刻不一样。

B.6 看懂电气图纸（二次图入门，能跟客户翻图）

  • 一次系统图（单线图）：用一条线代表三相，看主接线和柜列顺序（进线—计量—PT—出线—联络…，见 4.2）。
  • 二次原理图（展开图）：按"电流从上到下、从左到右流动"画逻辑，不按元件实际位置摆；同一个继电器的线圈和它的各个触点会被拆到不同回路里，用相同的文字编号关联。
  • 安装接线图 / 端子排图：告诉你线实际怎么接、接到哪个端子。
  • 看图心法：先找某个继电器的线圈在哪得电，再顺着找它的触点控制了谁。规律：线圈一得电，它所有常开触点闭合、常闭触点断开；一失电全部复原。

B.7 接地、零线与最容易混的安全概念

  • 火线 / 零线 N / 地线 PE：火线带电压、是来电端；零线 N 是工作回路、电流回去的路；地线 PE 正常不带电流，只在漏电时把电导入大地保命。
  • 接地系统一句话对号：TN-S=三火+N+PE 五根线、N 与 PE 全程分开（最规范，新工厂主流）；TN-C=N 和 PE 合并成一根 PEN（老四线）；TT=设备单独就地接地；IT=系统不接地/高阻接地（医院、矿山等要求供电高可靠场所）。销售不用会算，听到能对号即可。
  • 漏电 / 剩余电流 / 零序：正常时"出去多少电流=回来多少"，一旦有电流从绝缘破损处漏走，进出不等，差值就是剩余/零序电流，零序保护就是抓它。
  • 绝缘、爬电与凝露：绝缘电阻用 MΩ 衡量、越大越安全；高压件之间、高压件对地要留够空气间隙和爬电距离。潮湿凝露会让绝缘下降、发生爬电闪络——这正是柜内要用 THC 加热驱潮的原因。
  • 常见额定词：额定电流 In、额定电压 Un；IP 防护等级（第一位防尘、第二位防水，如 IP4X = 防 1mm 以上固体进入）；温升=通电发热允许比环境高出的温度。
  • 销售要点：接地刀位置、零序、绝缘监测的外围报警、IP 等级、防凝露都是成套柜验收必谈项，都能接到我们对应的元件（绝缘监测主机本身不是我们的，我们接它的越限报警输出）。

一客户行业的分类词最优先掌握

1.1 一次设备 / 二次设备

  • 一次设备：直接通过高压大电流的设备——变压器、断路器、隔离开关、互感器、母线。
  • 二次设备：不直接走大电流，做"测量、控制、保护、信号"的低电压小电流设备——继电器、变送器、温控器、信号报警器、开关电源、端子排。
  • 你卖的全部是二次元件。客户说"二次回路""二次图"，就是你的产品所在的那部分电路图。
  • 一次图 / 二次图：一次图画的是主电路（哪根母线接哪个断路器）；二次图画的是控制保护回路（继电器、变送器、指示灯、端子怎么接）。你的产品出现在二次图上。客户说"把你们型号反馈给画图的"= 设计院正在把你的型号画进二次图，好消息。

1.2 成套厂 / 本体厂

  • 成套厂：把断路器、互感器、继电器等买回来，组装成开关柜（KYN28、GGD、环网柜）卖出去。他们没有选型权，柜内元件按设计院图纸或业主指定采购——这就是你排除他们的原因。
  • 本体厂：自己制造设备本体（如断路器操作机构、变压器绕组），控制回路自己设计、元件自己选——选型权在他们手里，是你的目标客户。
  • 判断口诀：问对方"你们的电气图纸是自己设计院画的还是外来的？"自己画 = 有选型权。

1.3 电压等级

  • 日常术语：0.4kV（低压）/ 10kV / 35kV / 110kV / 220kV / 500kV。
  • 数字越大电压越高。10kV、35kV 是工业用户和新能源接入的常见等级——也是你客户最集中的领域。
  • 客户说"我们做 35kV 以下"，意思是他的产品用在 35kV 及以下电网。

1.4 kVA / kW

  • 变压器容量单位。SCB10-1000kVA/10kV = 树脂浇注干变、设计序号10、容量1000千伏安、电压10kV。
  • 一台 1000kVA 干变大约要配 1 套温控器（DTC/TC）——听到客户报年产能多少 kVA，心里就能估算温控器需求量。

1.5 变压器型号怎么读（见客户必备）

  • SCB / SCBH：S=三相，C=环氧树脂浇注，B=箔式绕组，H=非晶合金（加H=节能款）。
  • S11 / S13 / S20：油浸式变压器，数字越大越节能。
  • 干变 = 干式变压器（空气自冷/风冷，不泡油）；油变 = 油浸式。干变必配温控器，油变配油面温控计（较多用别的产品）——这就是你主攻干变厂的原因。
  • 箱变 = 箱式变电站（把变压器+开关柜装进一个铁箱子里）。美式箱变/欧式箱变是两种结构风格。

1.6 电网侧：国网 / 南网体系（客户最常报的身份）

  • 国网 / 南网：国家电网（覆盖 26 个省区市）/ 南方电网（广东、广西、云南、贵州、海南五省区；另外内蒙古的蒙西电网是独立省级电网，既不属国网也不属南网，遇到内蒙客户单独留意）。客户说"我们是国网的""南网的"= 电网系统的人。型式试验报告和体系认证齐全，是和电网体系客户对话的第一张牌；若公司已取得国网/南网入网资质再主动提，用前先确认有效期和覆盖品类，没核实就只讲型式试验报告和产品参数，别把"在办/过期"说成"已有"。
  • 省公司 / 地市供电公司 / 县公司：电网的三级管理层级。省公司定全省采购政策；地市局是实际用货和验收单位；县公司和你接触最多但权限最小。先搞清楚谁说了算再决定找谁。
  • 主网 / 配网 / 农网：电网三大业务板块。常见简化是主网 = 35kV 及以上（变电站、输电线路）、配网 = 10kV 及以下（配电室、开关柜、环网柜）、农网 = 农村电网改造；主配网并没有全国统一的硬性电压分界，35kV 在不少地区（尤其县域）按配网调度管理，也有以 110kV 为界的，客户口径不同顺着客户即可、别抬杠。你的产品三块都进：主网要求高（型式试验/业绩），配网量大，农网走量低价。
  • 三产 / 集体企业 / 多经：电网下属的"旁系企业"——送变电公司、电力安装公司、电力设计院、物资公司。大量施工、安装、运维、改造是它们干的，很多实际采购也走它们——这是绕开电网集采、直接对接的口子。
  • 国网商城 / 电商化采购：国网系统的线上采购平台。客户说"这单走国网商城"= 先完成平台入驻，价格流程全部线上化。

1.7 发电侧：电厂与新能源投资商（第二大类客户）

  • 五大发电集团：华能、大唐、华电、国家电投、国家能源——发电侧央企，旗下火电/水电/新能源电厂遍布全国。
  • 其他主流发电 / 新能源投资主体：五大发电之外，还有一批以新能源为主的发电投资商，坊间说的四小豪门、六小豪门就是这一类（这是坊间俗称、没有统一名单，常见的有华润电力、国投电力、中广核、三峡集团、中核集团、中节能，以及国家能源集团旗下国华电力等）——它们是光伏、风电、储能电站的主要业主，名单记个眼熟即可，别跟客户争论到底是几小。
  • 电源侧 / 电网侧：发电的一端（火电、水电、光伏、风电、储能）叫电源侧；输配用电的一端叫电网侧。客户说"我们做电源侧"= 面向发电厂和新能源场站供货。
  • 新能源投资商 / 电站业主：出钱建光伏风电储能站的主体——设备采购多走 EPC 和集成商，但品牌指定权在业主手里，业主点头比集成商点头更值钱。

1.8 按"谁出钱、谁选型"分客户类型（销售先分清这个，打法完全不同）

  • 配套型客户（BOM 型）：他们的产品里固定装你的元件（干变厂装温控器、开关柜厂装继电器）——单小但连续，进了 BOM 就锁定，最值得深耕，是你现阶段的主力。
  • 项目型客户：一单一议、跟着项目走（EPC、总包、招标项目）——单大但不连续，要盯项目信息、拼资质和价格。
  • 渠道型客户：经销商、贸易商，转手赚差价——价格敏感、忠诚度低，但能铺量，适合走量。
  • 终端用户 / 业主：最终用货的（电网公司、工厂、电站）——有品牌指定权，但采购走招标或集采，周期长。

1.12 前期拓客：先找对客户（新人第 1~2 周只干这一件事）

拓客不是撒网，是"选矿"——你 90% 的时间该花在 10% 能下单的客户身上。判断标准一句话：谁的图纸里能写进你的型号，谁就是第一优先级；选型权在哪，你就在哪使劲。记住：成套厂的图纸是设计院画的、业主定的，他自己写不进你的型号——所以成套厂永远不是第一优先级。（结合 1.8 客户类型看）

找错客户的 5 个典型样子（新人最常犯，白忙一个月）：

  • 把成套厂当 P0 磨——图纸是设计院画的、业主定的，他再想用你也写不进图。跑十家成套厂，不如搞定一张图纸（老销售的实战教训）。
  • 在贸易商身上磨一周——他不选型、只压价，聊得再深也进不了 BOM。
  • 找设计院要订单——设计院不下单，你的目标是"图纸上出现你的型号"。
  • 找终端业主推销，却不跟图纸——业主说了算但周期长，图纸源头在设计院，两头都得顾。
  • 撒网群发不聚焦——二次元件客户就三类人：画图的（设计院）、自己出设备的（本体厂/集成商）、按图施工的（成套厂），重心永远在前两类。

去哪找 P0/P1（获客渠道，按效率排）：

  • 中标公告：搜"干变 中标 / 直流屏 中标 / 断路器 中标 / 储能舱 中标"，顺着中标单位找本体厂、集成商——谁中标谁有活；同时记下公告里的设计单位，那是图纸源头。
  • 老客户转介绍：已成交的本体厂 / 集成商技术部、采购部的人，认识十个同行，让他介绍比陌拜高效十倍——前期每成交一家，都问一句"您还认识做同类设备的朋友吗"。
  • 行业展会：输配电、电力设备类展会，本体厂、集成商、设计院都来——带样册换名片，回来后一周内跟进。
  • 行业名录：干变厂 / 直流屏厂 / 箱变厂 / 断路器厂名录，按地区圈定，挨个电话约拜访。

2.1 继电器家族（型号最多、柜内用量最大）

下面的电流、时间、路数只帮你记住"谁大谁快、大概什么量级"，方便跟客户对得上话；精确参数、可选规格以最新产品说明书 / 产品手册为准，选型报价别只照这里抄。

先搞懂继电器到底是什么（30 秒）：它就是一个"用弱电控制强电、用一路信号控制多路通断"的电磁开关——内部一圈线圈，一通电产生磁力，把金属触点吸合或释放，触点那头接的电路就跟着接通/断开。为什么柜里非用它不可：保护装置、PLC 出来的信号很弱，带不动跳闸线圈、指示灯、警铃这些负载，而且一路信号往往要同时去好几个地方，必须靠继电器把信号放大、隔离、一分多路，所以它在二次回路里用量最大。另有固态继电器（SSR，半导体通断、无机械触点、动作快但怕过载发热）——这种全无触点的我们不做（见下方原理表第④类）。柜内控制回路用量最大的仍是电磁继电器；继电器按动作原理的完整四类分法（电磁 / 磁保持 / 静态 / 固态）和每个型号的归属，见下面的对照表。

▼ 继电器按"动作原理"怎么分（客户说电磁式 / 磁保持 / 静态 / 固态，你要接得住）

先分清两套维度：前面 RC、RDP、RL 这些是按"干什么用"（功能）分；电磁式、磁保持、静态是按"靠什么动作"（原理）分，两套维度不能硬对。下表按各系列的实际结构逐类归位，能确定对应的写明型号，拿不准的不写死、以最新说明书 / 技术答复为准。

按动作原理靠什么动作 / 特点我们对应的型号销售怎么记
① 电磁式（非保持 / 单位置，有触点）线圈通电产生磁力吸合衔铁、带动机械触点，断电靠弹簧弹回；要持续通电才保持、一断电就回默认位（单稳态），无需辅助电源、靠线圈自身工作，行业里就叫"非保持型单位置继电器"中间 / 接口：RC、RC-F、RC-V、RC-PTCD、RC-M、RC-P、RAI、RAI-V；断路器保护：RL-TBJ、RL-TBJ-Y、RL-I、RL-HBJ、RL-THW、RL-CBS、RL-PSS、RL-PSS-H、RL-UI；电磁型电源切换 RVS、RVS-NF、RVS-DC；无源时间 RT-NP、RT-E-NP（无源、无需辅助电源）；防跳+低气压闭锁 RN-FT（动作 / 返回电压、毫秒级动作、无电子电路，属电磁式集成）柜内用量最大的基本盘，客户说"普通电磁 / 有触点 / 机械式 / 单位置 / 无源继电器"就是它

③ 静态 / 电子式（数字电路，需辅助电源，出口仍可带机械触点）内部用数字电路 / 单片机实时采集、计算、整定后再驱动出口，必须接辅助电源，带数码管 / 显示 / 通讯；RML、RMY-T 这类就是"辅助电源 + 数码管整定 + MODBUS + 出口继电器接点"。注意：内部是电子的，但出口接点往往仍是机械触点（不是无触点）需辅助电源的数字式量度 RML、RML-F、RML-F-DC、RMY、RMY-DC、RMY-T；电子时间 RT、RT-X（需辅助电源、多模式 / 可编程）；智能电源切换模块 RMS（实时监测、过 / 欠压、RS485）；集成模块 RN-FB（辅助电源 + 时间整定 + 数码管）、RN-DK-A / RN-DK-C（电机控制）"静态继电器"=电子脑子 + 机械出口，我们有量度 / 模块这条线。注意量度里 RMY-K / RMY-K-N 是"无源拨盘型、无需辅助电源"，不属此类、内部结构以说明书为准；FA 报警器、温湿度 / 风机控制器、变送器（TE/TT/TS/THS/TG、SS 信号隔离器 / 安全栅）、开关电源也是电子装置，但不叫"继电器"
④ 固态 SSR / 光电（光耦）继电器——我们不做从输入到输出全程半导体 / 光耦合、完全没有机械触点和运动部件，动作快、无火花、寿命长，但怕过载发热、有微小漏电流；PhotoMOS 是 MOSFET 输出的光耦继电器。我们产品线没有这类产品无——我们的继电器产品线不做全无触点的固态 / 光电开关（别和第③类"静态"混：静态出口还有机械触点，固态是真的一个触点都没有）客户指定要"固态 / SSR / 光耦 / PhotoMOS 继电器"，别当场说我们有，记下来回公司找技术确认，以公司答复为准

几组最容易搅在一起的词，都是自家型号、务必分清：
① 电磁式 / 静态 / 固态三者别混：电磁式靠线圈机械动作；静态（RML 等需辅助电源的数字式量度）靠数字电路判断、但出口仍是机械触点；固态 SSR 连出口都是半导体、全机无触点，我们不做。
② 磁保持 ≠ 电气自保持：RDP 靠永久磁铁保持，线圈只通一下脉冲、平时不耗电；RL-HBJ"电流启动并自保持"是靠自身辅助触点把线圈锁住、持续通电（电气自保持 / seal-in），本质还是电磁式、线圈一直带电——名字都带"保持"，原理两码事。
③ 单稳态 ≠ 双稳态：普通电磁继电器是单稳态（通电吸合、断电弹回，只有一个稳定位）；磁保持是双稳态（合、分两个位置断电都能保持），"双位置继电器"正由此得名。
④ 客户嘴里的"永磁继电器"有时指方向敏感的极化继电器，听到先确认对方是不是要"给个脉冲就保持、不用一直通电"那种，拿不准回公司问技术，别凭名字报型号。
⑤ 同一系列里也可能分电磁 / 电子，别按系列名"想当然"：时间继电器 RT-NP / RT-E-NP 是无源（电磁类）、RT / RT-X 需辅助电源（电子类）；电源切换 RVS 是电磁立即切换、RMS 是带监测和通讯的电子模块；RN-FT 是电磁式、RN-FB 是电子式；RVSD 分单位置（电磁、失电返回）/ 双位置（磁保持、失电保持）；量度 RMY-K 无源拨盘、RML 带辅助电源数字式。判据就一条：要不要单独接辅助电源、有没有数码管 / 整定 / 通讯——要的是电子类，不要、靠线圈直接动作的是电磁类；拿不准一律以说明书 / 技术答复为准。

  • 刀闸机构控制模块（RN-DK-A，两工位）：用在普通两工位刀闸（隔离开关，只有分/合两个位置）的电动操作机构上，驱动 1 个串励电机正反转完成分/合，行程开关到位自动停机、靠外接制动电阻制动。一个导轨模块把电机正反转、过载与超时保护（电流异常或超时自动停电机并报警）、电机电流监测、合闸次数显示都集成起来；电机电源交直流自适应，电机功率 ≤800W，开出 3 常开 1 常闭、5A/250VAC，DIN35 导轨安装（电压规格、整定参数以说明书为准，销售先记住"两工位、一个串励电机、要制动电阻"即可）。
  • 三工位刀闸机构控制模块（RN-DK-C，三工位）：用在三工位刀闸（隔离合—分—接地合，一把刀三个位置）的电动机构上，一台驱动 隔刀、地刀 2 个永磁电机正反转（单台电机 ≤600W）。最大特点是内置三态联锁：处于隔离合位只响应隔离分闸、处于接地合位只响应接地分闸、电机转动中不接受新指令，从硬件上杜绝"带接地刀合隔离开关"的误操作；同时集成过载、超时、电机失电保护和操作间隔联锁、隔离合闸次数显示。它不用制动电阻，电源规格、接点容量、安装方式与 A 相同（整定参数以说明书为准，销售先记住"三工位、隔刀+地刀两个永磁电机、三态联锁、无制动电阻"即可）。
  • RN-DK 的边界务必分清（最容易报错）：RN-DK 管的是"电机怎么转、机构怎么动"——电动操作、电机保护、动作联锁这一层；而"刀闸/三工位现在在哪个位置、把位置信号反馈给后台"属于位置信号层，仍由双位置/中间继电器按辅助接点组合实现（以二次图为准）。它不是"三工位位置继电器"，两层会同时出现在一台柜里、互不替代。价值点：以前电机正反转+热继保护+延时+联锁要一堆分立器件搭，现在一个模块集成。
  • 电压继电器（RMY）：单相/三相过压、欠压、不平衡保护。RMY-K 是无源型（不需要辅助电源，8A 250VAC）、RMY-T 是同步检查继电器（并网/备自投合闸前检查压差、角差、频差）。
  • 电流继电器（RML）：单相/三相过流保护、三相电流不平衡保护，定时限。RML-F 交流反时限、RML-F-DC 直流反时限（电流越大跳得越快），均 5A 250VAC。
  • 整定值 / 整定范围：客户调的保护门槛数字（如"过流整定 5A"）；整定范围 = 这个门槛能调的最小~最大区间。报型号时客户常说"我要 5~10A 可整定的"。
  • 电源切换继电器（RVS 系列）：两路电源自动切换——RVS 双交流（AC1 优先，失电立即切 AC2、恢复立即切回，8A/16A 250VAC）、RVS-DC 双直流（DC1 优先，10A 220VDC）、RMS 精确切换模块（AC1 电压波动超范围就切，恢复且稳定一段时间才切回，5A 250VAC、切换功率≤1000VA）、RVSD PT 电压切换（双母线供电系统，3A 250VAC）、RVSD-TQ 同期电压切换装置（自动判断断路器/刀闸状态切换同期电压，3A 250VAC）。
  • 时间继电器（RT 系列）：收到信号后"延时"才动作。RT（上电延时/掉电延时/脉冲展宽三模式，有辅助电源，5A 250VAC）、RT-NP（无源无需辅助电源，启动功率>5W 可选，8A 250VAC）、RT-E-NP（无源带显示、体积小，5A 250VAC）、RT-X（循环定时，按设定时间反复动作/返回，5A 250VAC）。
  • 跳闸 / 合闸：断路器的"分 / 合"。客户说"跳闸回路"，就是控制断路器分闸的二次回路。
  • 辅助电源：给二次设备自身供电的电源（如 DC220V / AC220V / 85~265VAC 宽范围）。问清客户柜内辅助电源等级，直接决定你推荐哪个规格。

2.2 变送器家族（把现场量变成标准信号）

  • 变送器：把电流、电压、温度、挡位等信号转换成标准信号（4-20mA、RS485）送给仪表/后台。4-20mA 是工业标准模拟量信号——为什么是 4 不是 0？因为 0mA 意味着"断线"和"零值"分不清，4mA 是"活着"的最小信号。
  • 电量变送器（TE）：把电压/电流变成 4-20mA 或 RS485，配电柜"遥测"上传用。
  • 温度变送器（TT）：接 PT100、CU50 等测温电阻，把温度变成 4-20mA 远传后台。
  • 信号变送器（TS）：输入 4-20mA、RS485，输出 4-20mA、RS485——做信号隔离与变换的（转换信号制式、隔离干扰）。注意区分：TT 管"温度→4-20mA"，TS 管"信号→信号"（隔离/变换），别搞混。
  • 温湿度变送器（THS）：把柜内温湿度变成标准信号上传后台，后缀 -I = 4-20mA、-S = RS485（如 THS-I、THS-S），供电 9~30VDC。注意现行型号是 THS（旧资料曾写作 TTH，现行统一为 THS）。
  • 挡位变送器（TG）：把有载调压变压器的挡位变成 4-20mA 远传——电网调度要看主变在几挡。
  • RS485 / MODBUS：工业通信的"普通话"。变送器带 RS485 = 可以直接挂到客户的通信管理机上，走 MODBUS 协议被后台读取。客户说"要上后台""走通信"= 问带不带 RS485。

2.3 温控与温湿度家族（干变和柜子的"守护神"）

  • 干变温控器（DTC/TC）：干变的"体温计+守护神"。三相绕组各埋铂电阻（PT100）测温 + 第四路（环境或铁芯），超温先告警、再启动风机、最后跳闸。
  • 温控器（THC/THC-E）：采集一组温湿度信号，输出加热器、风扇、越限告警或 RS485 可选（THC-E 是无 RS485 的经济款）。THC-M 多功能型可接一组或两组温湿度，输出一路加热器、一路风扇和两路模拟量，带超温/潮湿/故障/断线告警。
  • 风机报警器（TCC）：监视干变冷却风机——输入温度信号或 CT，输出风机控制 + 风机断线告警。风机坏了干变会过热，客户常忽略这个测点——这是你的提醒话术。
  • 热电偶采集器（TK）：四路热电偶输入、四路超温告警接点——电厂、工业窑炉类高温测点用。热电偶 = 高温测温元件（几百上千度），和 PT100（中低温）分场景。
  • PT100 / CU50：最常见的测温电阻型号，PT100 测温范围宽（-40~200℃+）、CU50 便宜。必记住：客户说"埋的是 PT100"= 你接 TT/DTC 都能配。

2.4 信号报警家族（故障汇总的"喇叭"）

  • 信号报警器（FA/FA-I）：把分散的故障信号汇总报警——分体 FA / 一体 FA-I 基础款支持 8、16 路输入（如 FA8-8、FA16-16，输入与开出一一对应），点数更多另有 FA32 / FA48，最多 48 路无源信号输入。FA 分体式（主机和显示分开装）、FA-I 一体式。驱动光字牌、警铃、把事故信号送后台。
  • 光字牌：柜门上发光的报警窗，写"断路器跳闸""SF6报警"等字样——信号报警器的下游负载。

2.5 电源与变压器家族（二次设备的"饭"）

  • 开关电源（YDSP）：把交流 100~240V（交直流通用）变成稳定的直流（110VDC/220VDC）给二次设备供电。功率分 120W/240W/600W/1000W。柜内直流元件越多，开关电源需求越大——和继电器是捆绑关系。
  • 二极管冗余模块（DPM）：两台开关电源并联互为备份，一台坏了另一台顶上，重要负载（保护、监控）不掉电。客户说"供电不能断""要冗余"= DPM 的机会。
  • 控制变压器（XF）：电压转换（常见 380V 转 100V），负载阻抗≥50K、精度 1%、单相三相可选——给进口设备/仪表/特殊电压等级负载供电用。

2.6 读型号：看一眼前缀就知道是什么（背家族缩写）

  • 第一个字母决定家族：
    • R 开头 = 继电器家族：RC 中间、RDP 双位置、RMY 电压、RML 电流、RL- 断路器保护、RN- 集成/机构控制模块（RN-FT 防跳+气压闭锁、RN-FB 非全相、RN-DK 刀闸机构电机控制）、RVS/RMS 电源切换、RT 时间、RAI 抗干扰——看到 R 就知道是继电器，再按第二个字母归位。
    • T 开头 = 温度/变送家族：TT 温度变送、TS 信号变送、TG 挡位变送、THS 温湿度变送、TC/TCC/TK 温控测温。
    • TE = 电量变送（电→信号，不是温度，别和 TT 混）。
    • THC = 温湿度控制器（本地自动动作）；DTC = 干变温控器。
    • F 开头 = 信号报警：FA / FA-I（故障汇总）。
    • Y 开头 = 电源：YDSP 开关电源；DPM 冗余模块；XF 控制变压器。
  • 后缀代表"变种"（认后缀能答上"这是哪一档"）：
    • -F 快速（RC-F ≤7ms）或反时限（RML-F）；
    • -V 直流负载型（RC-V、RAI-V）；
    • -E 增强/带显示（RDP-E 互锁、RT-E-NP 带显示、THC-E）；
    • -M 模组/多功能（RC-M、THC-M）；
    • -NP 无源型（RT-NP、RT-E-NP，不需辅助电源）；
    • -S 单线圈（RDP-S）；-L 锁存/带指示灯（RDP-L）；
    • -DW 直流操作（RL-TBJ-DW）；-DC 直流型（RVS-DC、RML-F-DC）；
    • -T 同步检查（RMY-T）；-K 无源型（RMY-K）。
  • 实战用法：客户电话里报"RL-TBJ-DW"，你 1 秒反应"断路器防跳、直流操作型"——比翻目录快，专业感直接拉满。

三技术替代、同行品牌与配套邻居谁把料做没 · 谁抢同一颗料 · 谁带你走量

3.0 先分清三种关系：技术替代、同行品牌、配套邻居

客户张口就是"KYN28 二次室""直流屏控母""凝露加热""我们一直用某牌子"——这一章先把柜里、回路里的各种东西，按"它跟我们是什么关系"分成三类。分清楚了，才知道眼前这个东西该防、该拼、还是该搭车，也不会把两种完全不同的"竞争"混成一锅粥。

关系它是什么对继电器用量的影响你该怎么动
技术替代
（替代路线）		不是同行厂家，而是另一条技术路线——用芯片、程序把原来一堆继电器干的活集成掉（代表：微机保护、PLC）把一部分继电器"做没"，单柜颗数变少；但替代不干净，操作、出口、硬联锁这层仍要独立件不跟它拼算法 / 逻辑，专攻它"装置之外"仍要配的接点扩展、操作回路、硬接线后备

一句话分清：技术替代是"把这颗料做没"（拼的是路线），同行品牌是"抢这颗料"（拼同款谁更好），配套邻居是"要用这颗料"（它是你的下游）。平时嘴里说的"竞品"，严格讲只对应第二类"同行品牌"；第一类别叫竞品，叫技术替代，两类的应对思路完全不同。

3.1 技术替代：微机保护和 PLC，到底替代了什么、替代不了什么

这两样不是另一家继电器厂，而是两条"用电子和程序替代硬接线继电器"的路线。新人最怕两种极端：要么觉得"上了综保 / PLC，继电器就没戏了"，要么跟客户犟"这东西不可靠别用"——两种都是外行话。看清楚它的替代边界，边界之外全是你的单。

3.1.1 微机保护装置（综保 / 微保）

它是什么：把过流、过压、差动这类"测量 + 保护判断"写进程序的电子装置，一台替代传统一整套保护继电器，还带通讯、能上后台，成套厂的中高压柜里大量使用。

它替代的是哪一层：主要是"动脑判断"那一层——量度、保护逻辑、定值计算、故障录波和通讯上报（对应量度 RML / RMY 类在"判断"环节的部分场景）。

它替代不干净、仍要独立继电器的地方（重点，逐条记）：

  • ① 出口接点不够、容量小：装置自带的开出接点组数有限、多为信号级小容量，真要去跳分合闸线圈、点亮信号、做多路闭锁和录波，得靠中间继电器 RC 做接点扩展（一组变多组）、容量放大、电气隔离。
  • ② 断路器操作回路是硬接线：防跳 RL-TBJ、跳 / 合位监视 RL-THW、跳合闸回路监视 RL-CBS、电源监视 RL-PSS、SF6 低气压闭锁 RN-FT，属于操动机构 / 操作箱回路，讲究可靠、抗干扰、失电安全，传统就是独立专用继电器。即便部分综保内置操作回路，也常因接点不够、要冗余、老柜改造而外配——以客户二次图为准，别默认"上了综保就全集成"。
  • ③ 位置信号要重动 / 扩展：断路器、刀闸的一副辅助接点，往往要同时送给信号、闭锁、录波、后台好几路，用 RDP 双位置 / 重动继电器把一对接点扩展成多路，装置没有那么多物理接点。
  • ④ 强干扰隔离 + 失电兜底：分合闸线圈断电瞬间有反向电动势，电子口娇气，机械继电器做硬隔离更耐造；装置死机或失电时，关键报警、跳闸、联锁要有不依赖程序的硬接线后备（电源监视、故障报警接点这类）。
  • ⑤ 大量柜体根本不用综保：普通环网柜、充气柜、端子箱 / 汇控柜、双电源柜、风机水泵 / 消防 / 电梯控制柜，要么没有保护算法需求，要么要硬接线毫秒级动作（如双电源切换 RVS），用继电器反而更省、更可靠、更好维护。

3.1.2 PLC（可编程逻辑控制器）

它是什么：工业控制计算机，用程序代替"一堆中间继电器搭出来的联锁、顺序、定时逻辑"。

它替代的是哪一层："逻辑运算"那一层——原来用一排 RC 搭的与或非、互锁、顺控、定时，写进程序能省掉一批中间继电器。

它替代不干净的地方：

  • ① 输出点带不动负载：PLC 输出是晶体管或小型继电器点、容量小，带接触器线圈、电磁阀、指示灯、电机，都得经中间继电器 RC 或接触器做"小控大"。
  • ② 安全相关要硬接线：急停、安全联锁、关键跳闸为满足可靠性，规范上常要求不进程序、用硬接线直接实现（程序会死机、扫描有周期），这部分继电器省不掉。
  • ③ 简单固定逻辑不划算：就几个联锁、逻辑永不变的柜子，上 PLC 要配电源模块、要编程、要通讯，成本和故障点都比一排继电器高，客户反而选硬接线。
  • ④ 现场要好维护：继电器坏了换一颗、电工都会；PLC 要会读程序，偏远 / 无人值守站点更认硬接线。

两个坑别踩：① 别跟客户说"综保 / PLC 不可靠、别用"，这是外行话；正确表达是"装置管判断和逻辑，操作、出口这一层用独立继电器更稳妥、接点也够、还好检修"。② 越是规范的盘厂越懂"分层"——接点扩展、操作回路本就是标准外配，你讲得越专业越有的聊。现场就问三句切进去：装置几路开出 / 接点多大？操作回路是装置自带还是外配？位置信号要送几路？

3.1.3 一套二次回路分几层：哪层被程序拿走、哪层继电器还在（最该吃透的一张表）

跟客户聊"综保 / PLC 会不会把继电器替代完"，别笼统回答。把一套控制 / 保护回路从上到下拆成功能层，一层一层看：谁干的、能不能被集成、独立继电器还在不在，一目了然。

一句防外行话的澄清：综保 / PLC 里面其实也有继电器（装置自带的出口 / 操作继电器），但那是装在装置内部、路数和容量固定、不单独对外供货的小件。我们做的是装置之外、导轨上独立安装的继电器——客户要加路数、换大容量、做隔离 / 冗余、老柜改造、或装置不带操作回路时，外配的就是这一类。所以别说"综保里没有继电器"，准确说法是"装置内置的接点不够用 / 不合适，操作和出口这一层要独立外配"。

3.1.4 电子时代，独立继电器反而更稳的六个场景（被问"为什么不全用程序"时这么答）

  • ① 成本：就几个固定联锁 / 切换，上一套装置要配电源、组态、调试，一排继电器更便宜，客户算账常选硬接线。
  • ② 可靠性 / 失电安全：继电器动作只靠线圈和触点，不依赖程序、不依赖通讯，掉电 / 死机不影响硬接线回路按设计返回或动作（fail-safe）。
  • ③ 抗干扰：分合闸线圈、变频器、雷击浪涌环境电磁干扰强，机械触点做物理隔离，比娇贵的电子口更耐冲击。
  • ④ 好维护：继电器坏了换一颗，现场电工都会、备件通用、不用接电脑读程序；装置 / PLC 要专业人员组态，偏远无人值守站更认硬接线。
  • ⑤ 交付快：硬接线即接即用，不用编程、不用管软件版本，急单、改造、抢修时优势明显。
  • ⑥ 短时耐受：机械触点对短时过载、浪涌电流的承受能力强于半导体输出口，出口带线圈类感性负载更稳。

顺带分清综保和 PLC（别在客户面前混）：综保面向电力系统保护——测电压电流、算过流 / 差动等故障、动作是去跳断路器保一次设备安全，要符合电力行业标准；PLC面向工业过程控制——管生产线 / 设备的逻辑、顺控、联锁动作。两者都"用程序"，但行业、认证、I/O 结构不同。另外行业在推一二次融合（把保护、操作、通讯做进开关本体的智能柜），集成度更高，这是趋势不用抵触；我们的增量在装置外配、老柜改造、备件更换，以及大量根本不用综保 / PLC 的简单柜体。

3.2 配套邻居（共生件）：谁出货，谁就带你走量

配套邻居不抢继电器的单，反而是继电器的"载体"——它们的主设备、柜子、回路里必须装继电器。邻居越火、出货越多，你的件跟着走量。做这类客户，本质是把继电器设计进它的标配 BOM。

3.2.1 开关类邻居（主设备，必有二次回路）

  • 断路器：能接通、承载并切断故障短路电流，是开关柜核心。它的操动机构里全是分合闸、防跳、位置监视、闭锁等二次回路，是继电器最刚性的需求来源。
  • 负荷开关：只能分合正常负荷电流、不能切短路电流，操动机构里同样有二次回路（环网柜主力开关）。
  • 隔离开关（刀闸）：只提供可见断口、没有灭弧能力；电动操作型才有电机控制回路（RN-DK 机构控制模块就是配它的电动机构），手动型不用。

3.2.2 控制与测量类邻居（小控大、取信号）

  • 接触器：外形和继电器很像，但用来通断大电流（电机、加热等负载）。两者是经典前后级配合、不是竞争：继电器接点小（信号级），先去控制接触器线圈；接触器主触点大，再去带负载——这就是"小控大"。一句话分开：继电器传信号，接触器带负载，客户搞混时你要能讲清。
  • 互感器（CT / PT，新标 TA / TV）：把大电流 / 高电压按比例缩小，给仪表、保护、量度继电器用。CT=电流、PT=电压；变比如 600/5 = 一次 600A 变二次 5A。它的二次侧正是量度继电器、变送器、仪表的输入来源——有量度 / 变送 / 测量的柜子必配互感器，是天然配套关系。

3.2.3 成套 / 系统类邻居（控制柜多，继电器用量大户）

  • SVG / SVC：动态 / 静态无功补偿装置，由电容器、电抗器加一面面控制柜组成，每面控制柜都要操作、联锁、切换、信号继电器，用量大。
  • UPS / EPS / HVDC：不间断电源 / 应急电源 / 高压直流，数据中心和关键负荷配套，内部整流、逆变、旁路切换都要控制与切换元件，是二次元件大户。
  • PCS / BMS：储能变流器 / 电池管理系统，储能电站两大核心，外加汇流、升压、温控一堆控制柜，都带二次回路。
  • DTU / FTU / TTU：配网自动化终端（站所 / 馈线 / 配变），本身是终端设备，但内部和外接的操作、信号、电源回路仍要独立继电器做出口与隔离。
  • 四遥：遥测、遥信、遥控、遥调——电网远程监控的四种功能。遥测是变送器的活（TE/TT/THS），遥信是信号继电器 / 报警器的活（RC/FA）——听到"四遥"就想到变送器 + 信号两条线。

客户嘴里说的每台设备，都是「一次本体 + 二次回路」的组合。这一章按统一骨架解剖设备：它是什么、解决什么问题、里面装什么、我们的产品装在哪、客户怎么描述它、拜访时盯什么。设备细节与应用位在第四章有更完整的展开，两边对照看。

四应用设备扫盲你的产品都装在哪些柜子里 · 跑客户必背

客户张口就是"KYN28 二次室""直流屏控母""汇控柜""凝露加热""温度上后台"——这一章让你立刻反应出：那是你哪个产品的家，以及它在里面干什么活。

先记住一条链：电从哪来到哪去。发电厂 → 升压站（110/220kV 高压远距离送电）→ 变电站逐级降压 → 10kV 配电室 → 变压器降到 0.4kV → 工厂/楼宇/家庭。你的产品全部落在这条链的"变电站 → 配电室 → 末端设备"这一段（10kV 及以下为主）。客户嘴里任何一个柜子、任何一句话，都能在这条链上找到位置——先定位它在链条哪一环，就知道该聊什么、该推什么。这条链背下来，你就比 80% 的同行"懂行业"。

4.1 先搞懂三个"地方"（客户的一切都发生在这三个地方）

  • 变电站：电网的"大枢纽"，电压等级高（35kV 及以上），里面一排排间隔（间隔 = 一个完整的进线/出线单元，含一面开关柜或一套设备+保护）。电网公司建的。
  • 配电室 / 配电房：工厂、楼宇、小区里的"小枢纽"：10kV 进来，经变压器降到 0.4kV 分给各车间各楼层。你客户的柜子和干变，最终大部分装在这里。
  • 开闭所：城市里常见，不降压、只做分合分配的 10kV 中转站（把一路 10kV 分成几路再送出去）。
  • 派生词：升压站（新能源场站/电厂里把电升到 35kV/110kV 送出去的变电站——光伏、风电场必配）；预装式变电站/预制舱（把二次设备整舱在工厂装好，拉到现场吊装——新能源场站主流做法，舱内二次元件在工厂预装=本体厂/集成商的选型权）。
  • 新能源场站（现在增长最快的四个场景）：光伏电站 = 光伏板阵列 + 汇流箱 + 逆变器 + 箱变 + 升压站；风电场 = 风机（机舱 + 塔筒）+ 箱变 + 升压站；储能电站 = PCS 舱 + 电池舱 + 升压站；充电场站 = 箱变 + 充电桩群。它们本质是"没有传统变电站的配电 + 升压"组合，二次元件需求跟传统变电站同级甚至更高——新能源客户是目前最肥的客户群，且选型权常在集成商/本体厂手里，正是你的目标。

4.2 柜子全家福（一排配电柜从左到右的完整顺序）

一条典型 10kV 配电室的柜列：进线柜 → 计量柜 → PT柜 → 出线/馈线柜（多面）→ 联络柜 → 无功补偿柜 → 直流屏 → 通信柜

  • 开关柜（总称）：装断路器+二次元件的柜子统称，高压柜（10~35kV）和低压柜（0.4kV）都算。柜 vs 屏：配电现场叫"柜"（开关柜、直流柜），电站里立起来一排的专业设备叫"屏"（保护屏、直流屏、远动屏）——本质都是"柜子+二次设备"。
  • KYN28（中置柜）：最常见的 10kV 金属铠装移开式开关柜。K=铠装，Y=移开式，N=户内，28=设计序号。断路器装在手车上（可像抽屉一样拉出检修），中置=手车在柜子中间层。柜顶正面那格叫"继电器室/二次室（低压室）"——你的中间继电器、信号继电器就住在这里。 客户说"二次室空间太挤"= 小型化/可拔插结构的切入点。我们在这：RC/RC-P 中间继电器、RT 时间继电器、THC 温湿度控制器（防凝露）、YDSP 开关电源。
  • XGN / HXGN（固定式柜/环网柜）：XGN=固定式金属封闭柜（断路器固定装，检修要停电）；HXGN=环网柜（行业英文简称 RMU，Ring Main Unit），体积小、装负荷开关，城市配网"环网"主干用，外资厂和出口单常直接叫 RMU。环网柜空间更小，小型导轨式/可拔插继电器、温湿度控制器（THC 防凝露）的机会。 我们在这：RC 中间继电器（含小型可拔插型）、THC 温湿度控制器、RVS 双电源切换继电器。
  • 充气柜（C-GIS，气体绝缘开关柜）：把断路器/负荷开关、隔离开关、母线等高压带电部分全部密封进钢板气箱、箱内充绝缘气体的中压柜，全绝缘、全密封、免维护、体积小，抗潮湿、抗污秽、抗盐雾，地下配电室、紧凑站房、沿海和高海拔用得多。两个维度最容易说错，务必分清：①"充气柜"按绝缘/密封方式命名，"环网柜"按用途（环网供电）命名，两者有交叉——既有充气式环网柜，也有空气绝缘环网柜（HXGN）；充气柜也能做成断路器馈线柜，不一定是环网柜。②它和 GIS 是大小两码事：GIS 是变电站里的大型组合电器（电压等级高、按间隔组合），C-GIS 是配电级整柜密封，常见 12/24/40.5kV。气箱里传统充 SF6，现在越来越多改用干燥空气、氮气等环保气体（SF6 是强温室气体，受限）。我们在这：三工位/开关位置重动（双位置+中间继电器按辅助接点组合，以图为准）、小型可拔插中间继电器 RC-P、THC 防凝露（地下/户外尤其要）；若三工位是电动操作机构，电机正反转控制与三态联锁另用 RN-DK-C 一台（位置反馈仍走组合继电器，两层不冲突）。两个边界别报错：只有充 SF6 的柜才用得上 RN-FT 的低气压闭锁，环保气体柜、固体柜没有"SF6 气压"这一说；只有断路器型充气柜才用防跳 RL-TBJ，负荷开关-熔断器型不用防跳。
  • 固体绝缘柜 / 环保气体柜（和充气柜并列、客户常一起提）：固体绝缘柜（SIS）用环氧树脂把带电体浇注封死、柜内没有绝缘气体，也就没有漏气和气压问题；环保气体柜结构同充气柜，但把 SF6 换成干燥空气/氮气/环保混合气体。三者都走"小型化、全密封、免维护"路线，二次元件用法和充气柜基本一致（位置重动＋小型中间＋防凝露），唯一区别：固体柜和环保气体柜都没有 SF6 低气压闭锁，RN-FT 的气压功能用不上，别按充气柜照搬。
  • 隔离柜 / 站用变柜 / 避雷器柜（一排柜里剩下的功能柜）：隔离柜装隔离开关或隔离手车，检修时给出一个看得见的明显断开点（它不切负荷电流）；站用变柜（所用变柜）柜内装一台小变压器把 10kV 变 0.4kV，给本站照明、加热、直流屏充电等自用电供电；避雷器柜（PT 避雷器柜）装避雷器吸收雷击和操作过电压，常和 PT 柜合并。这些柜的二次室同样要位置指示、信号报警和防凝露，是 RC、FA、THC 的补充用量位。
  • 电缆分支箱 / 环网箱 / JP 柜（户外配网三件套，配网改造量大）：电缆分支箱（DFW）=路边把一路电缆分成几路的铁箱，普通型只做电缆分接、不含开关（基本不用继电器），带负荷开关的才有位置指示；环网箱（户外环网柜/开闭箱）=放到户外的环网柜组合、配 DTU 上后台，三工位位置重动、防凝露、变送器都要；JP 柜（综合配电箱）=挂在柱上变压器下方的低压箱，把配电、计量、无功补偿、漏电保护做进一个箱，农网/台网改造标配，低压小型中间继电器、信号器有零散用量。听到"配网、台变、农网"就对号这三件套。

  • GGD / GCS / GCK / MNS：都是低压柜（0.4kV）型号——GGD 固定面板式（最普及）；GCS/GCK/MNS 抽屉柜（每个回路做成小抽屉，内装断路器+接触器+中间继电器+时间继电器）。低压成套厂的地盘，量大但选型权常在终端/设计院。 我们在这：RC 中间继电器、RT 时间继电器、FA 信号报警器、THC 温湿度控制器。
  • MCC / 动力中心（电机控制中心）：0.4kV 集中管理几十台电机的抽屉柜列，每台电机一个抽屉（断路器+接触器+热继电器+中间继电器+时间继电器）。电机类工厂、水厂、电厂辅机都是 MCC，是中间/时间继电器用量最大的柜型之一。 我们在这：RC 中间继电器（顺序启动/星三角/互锁）、RT 时间继电器（延时/循环）、THC 柜内防凝露、FA 信号报警器（电机故障汇总）。
  • 配电柜 vs 配电箱：大个立地上的叫柜，小个挂墙上的叫箱（照明箱 AL、动力箱 AP）。箱子里也有继电器，量小。
  • 动力柜（AP）/ 照明箱（AL）：给电机/照明配电的末端柜，接触器+中间继电器+时间继电器的用量大户（电机顺序启动、星三角切换、互锁）。
  • 进线柜 / 出线柜（馈线柜）：电源进来的柜 / 电分出去的柜。"馈线"= 分出去的线路。
  • 计量柜 / PT柜：装电表计量的柜 / 装电压互感器的柜。PT柜里的电压继电器（RMY）监视母线电压（欠压/过压告警）、电量变送器（TE）把计量数据送后台——这是你变送器和电压继电器的经典应用位。 我们在这：RMY 电压继电器（母线电压监视）、TE 电量变送器（遥测上传）。
  • 联络柜（母联柜）：把两段母线连起来的柜。两路电源互为备用时由它切换——"备自投（BZT）"= 备用电源自动投入，就是母联柜自动合闸的逻辑；并网/备自投合闸前要"检同期"，同步检查继电器（RMY-T）就是干这个的；双电源切换继电器（RVS）是执行元件。 我们在这：RMY-T 同步检查继电器、RVS 电源切换继电器、RC 中间继电器（出口回路）。
  • 无功补偿柜（电容柜）：装电容器组提高功率因数（避免被电网罚款），电容器投切回路的延时/联锁用时间继电器、中间继电器。同一排电能质量柜还会听到：SVG（静止无功发生器，动态补无功）、APF（有源电力滤波器，滤谐波）、SVC（静止无功补偿装置）——都是电容柜的升级/同类，柜内控制、投切、报警元件相通。我们在这：RT 时间继电器（投切延时）、RC 中间继电器（联锁）、THC 柜内温控（电容柜发热）。
  • 变频柜 / 软启动柜：装变频器或软启动器的柜子，控制电机调速/平滑启动。变频器是电磁干扰源，旁边继电器容易误动——这是 RAI 抗干扰继电器的招牌场景。 我们在这：RAI/RAI-V 抗干扰继电器（变频器旁）、THC 温湿度控制器（变频器发热大要散热/防凝露）、YDSP 开关电源（给控制板供电）。
  • 直流屏（直流电源柜 / 直流系统，常见型号 GZDW＝柜式·直流·电力·微机控制）：变电站/配电室的"心脏起搏器"——柜内蓄电池组 + 充电模块，平时给全站二次设备供电，交流电全停时靠电池撑住——保护和断路器跳合闸一刻都离不开它。客户必查、验收必看的核心柜：
    • 合母 / 控母（HM / KM）：合闸母线（电压高，如 DC220V，给合闸线圈瞬间大电流）；控制母线（给保护、仪表、继电器的小电流电源）。合母经硅链（降压硅堆）降到控母等级。客户说"控母电压监视"= 你电压继电器（RMY）的活。
    • 浮充 / 均充：平时小电流"浮充"养电池；定期大电流"均充"补足。直流屏维护的高频词。
    • 绝缘监测：直流系统有一极对地绝缘坏了可能误动——绝缘监测装置（绝缘监测仪）监视正/负母线对地绝缘。注意：绝缘监测装置、充电模块、电池巡检仪本身是别家专用主机、不在我们产品线里；我们供的是它们外围的电压监视（RMY）、故障报警（FA）、中间（RC）和柜内供电（YDSP/DPM），别把整套主机报成自家产品。
    • 电池/母线电压监视（电池巡检仪的外围）：电池组和母线电压越限要报警——逐节巡检每一节电池是专用电池巡检仪（别家主机），我们用电压继电器 RMY + 信号报警器 FA 输出光字/音响报警，做的是"越限报警"这一环。
    • 闪光回路：事故时指示灯闪烁提示值班员，老站用闪光继电器（本公司型号表无此专用件，听懂名词即可，别给客户报价）。
    • 一句话：直流屏里中间继电器、电压继电器、双位置、信号报警器大量使用，柜内直流供电还用到开关电源（YDSP）和冗余模块（DPM）——听到客户做直流屏/直流电源，直接报全系列。
    • 我们在这（直流屏我们能供的）：RMY 电压继电器（合母/控母电压监视）、RDP 双位置继电器（两态位置保持）、RC 中间继电器、FA 信号报警器（故障汇总报警）、YDSP 开关电源 + DPM 冗余模块（柜内供电）。充电模块、绝缘监测装置、电池巡检仪是别家专用主机、不是我们的件，只做它们外围的监视、报警、供电配套，别整台报成自家的。
  • 一体化电源柜（智能一体化电源系统）：新建变电站的主流配置——把直流屏、UPS、通信电源、逆变电源合成一个柜、共享一组蓄电池。客户说"做一体化电源"= 还是直流屏那套元件，只是柜子合并了。我们在这：同直流屏全系列（RMY/RDP/FA/YDSP/DPM），外加 UPS 相关变送与切换。
  • 通信屏 / 远动屏：装通信管理机、四遥设备的屏（把现场信号送电网后台）。"温度/电流要上传"= 变送器（TT/TE）挂到这面屏的机会。 我们在这：TT 温度变送器、TE 电量变送器、THS 温湿度变送器（RS485 直挂通信管理机）。
  • DTU / FTU 站所终端柜（配网自动化柜）：装配网自动化终端的户外/户内柜——DTU（站所终端，Distribution Terminal Unit，管整个配电室/开闭所）、FTU（馈线终端，Feeder Terminal Unit，管一条出线）、TTU（配变终端，Transformer Terminal Unit，管一台台变/箱变）。做配网自动化的客户=变送器+开关电源的稳定客户。 我们在这：TE 电量变送器（电压/电流采集）、RS485 通信配套、YDSP 开关电源、THC 户外柜防凝露。
  • UPS / EPS 屏：UPS（Uninterruptible Power Supply，不间断电源，平时在线、停电无缝顶上，机房用）/ EPS（Emergency Power Supply，应急电源，平时待机、事故才投，消防应急用），都是交流电源柜，内含切换与控制回路。
  • 箱变（箱式变电站）：变压器+高压柜+低压柜整套装进一个箱体，工厂预装、现场吊装。分三种风格：欧式（学名预装式变电站，型号 YBM/YBP，高压室、变压器室、低压室隔间齐全，像个小铁房）、美式（学名组合式变压器，型号 ZGS，以变压器本体为主、元件外挂，更紧凑）、华式（介于欧美之间的国产紧凑型，新能源箱变多用）。箱变里的干变同样要装温控器（DTC/TC）——干变厂接箱变订单 = 温控器跟着走。 我们在这：DTC/TC 干变温控器、RVS 双电源切换（箱变常有双回路）、RL-TBJ 防跳、RDP 双位置、THC 箱内防凝露。
  • 端子箱 / 汇控柜：户外设备旁的小柜子。端子箱=电缆中转接线；汇控柜=GIS/户外断路器旁的"大脑"，汇集本间隔全部二次回路（跳合闸、信号、闭锁、加热驱潮）。汇控柜里防跳、双位置、非全相、SF6闭锁继电器、温湿度控制器（防凝露）全套都装——断路器厂/GIS厂/集成商是 RN 系列的客户。 我们在这：RL-TBJ 防跳、RDP 双位置、RN-FB 非全相、RN-FT 防跳+SF6闭锁、THC 驱潮加热、YDSP 柜内供电——汇控柜=RN 系列全家福。
  • GIS（气体绝缘金属封闭组合电器/开关设备，Gas Insulated Switchgear）：把断路器、隔离开关、母线全封进金属筒充 SF6 气体，占地小、可靠性高——城市变电站和新能源升压站主流。记住大小对应：GIS 是变电站级大型组合电器，C-GIS（前面的充气柜）是配电级整柜，差一个 C（Cubicle，箱/柜式）。每个 GIS 间隔配一台汇控柜=每个间隔都是你的继电器容量。 我们在这：同汇控柜全套（RN 系列是核心，SF6 低气压监视就是 RN-FT 的招牌功能）。

4.3 断路器与操作机构（防跳/双位置/非全相的"家"）

  • 断路器本体 vs 操作机构：本体管"灭弧+分合电流"；机构是"肌肉"——弹簧储能、分合闸线圈、辅助开关都在机构箱里。操作机构厂 = 你的核心目标客户。
  • 一次开关/互感器的字母代号（图纸、外资厂、标书里常直接用）：CB＝断路器（Circuit Breaker），其中 VCB＝真空断路器（Vacuum CB，VS1/ZN63 都是 VCB）；LBS＝负荷开关（Load Break Switch，环网柜里那台）；DS＝隔离开关（Disconnect Switch）；ES＝接地开关（Earth Switch，三工位里的"接地"那一刀）；FU＝熔断器。互感器：CT＝电流互感器（新国标写 TA）、PT＝电压互感器（新国标写 TV），新老标注图纸上都会遇到，指的是同一个东西。
  • 弹簧操作机构 / 永磁机构：两种主流。弹簧机构 = 电机拉紧弹簧储能、释放完成分合闸。
  • 储能：合闸弹簧上紧的过程。客户说"储能回路"= 控制储能电机的二次回路（储能电机控制用中间继电器+时间继电器）。
  • 合闸线圈（YC）/ 分闸线圈（YT）：通电即动作的"电磁扳机"。你的继电器控制的最终对象就是这两个线圈——客户说"防跳回路"，防的就是合闸信号粘住导致合闸线圈反复受电、断路器在故障上反复分合（"跳跃"），几秒就烧机构。
  • 防跳继电器（RL-TBJ）：装在断路器控制回路，标准配置——听到"防跳"两个字=掏 RL-TBJ。
  • 三相不一致 / 非全相（RN-FB）：220kV 及以上大断路器分相操作（A/B/C 三相各自一个机构），故障时可能只跳开一相——非全相运行对电网危害大，需延时三跳。RN-FB 装在汇控柜/端子箱里监视三相位置并延时跳三相。
  • SF6 低气压闭锁（RN-FT 的功能之一）：SF6 气压低于闭锁值 = 灭弧能力不足，此时闭锁分合闸（强行操作=放电事故）。RN-FT = 防跳 + 低气压闭锁二合一，一个继电器顶两个功能位。
  • 行程开关 / 辅助开关（位置触点）：机构上随断路器位置联动的机械触点，给二次回路发"已合/已分"信号——双位置继电器（RDP）和跳合位监视继电器（RL-THW）就是用来监视和保持这些位置的。
  • 我们在这（断路器操作机构全家桶）：RL-TBJ 防跳继电器、RDP 双位置继电器、RL-THW 跳合位监视、RL-CBS 跳合闸回路监视、RL-PSS 电源监视、RN-FB 非全相（分相机构）、RN-FT 防跳+SF6 闭锁、RL-TBJ-DW 直流操作型（直流操作机构）。
  • 隔离开关 / 接地开关（刀闸）的电动操作机构（RN-DK 系列，别和断路器机构混）：断路器靠弹簧储能机构、要防跳；刀闸（DS/ES）很多是用电机直接驱动正反转来分合。这套"电机正反转 + 行程开关到位停 + 过载/超时保护 + 联锁"，过去要用接触器、热继电器、时间继电器、中间继电器一堆搭，现在专用模块集成：普通两工位刀闸（1 个串励电机、要接制动电阻）用 RN-DK-A；三工位刀闸（隔刀+地刀 2 个永磁电机、要三态联锁）用 RN-DK-C。再强调一次：RN-DK 负责电机动作，刀闸位置反馈后台仍走双位置/中间继电器组合，是两层东西。

4.4 二次回路"黑话"（听懂客户讨论图纸）

  • 控制回路 / 信号回路 / 测量回路：跳合闸指令走的路 / 位置与报警上传的路 / CT/PT 信号进仪表的路。你的产品横跨三者——控制回路=继电器家族，信号回路=信号继电器/报警器，测量回路=变送器家族。
  • TWJ / HWJ（跳闸位置继电器 / 合闸位置继电器）：监视断路器在分位还是合位的继电器——专用件是跳合位监视继电器 RL-THW（想和防跳合一就选 RL-TBJ-DW）；RDP 双位置也能做通用位置保持，但不是这个用途的专用件，别混报。客户说"TWJ 不励磁了"= 跳位监视回路故障。
  • 屏顶小母线：一排屏柜顶上贯穿的共用电源铜排（控制电源、信号电源、闪光母线等），每面屏从屏顶取电。
  • 母线 / 母线桥 / 母线槽（三个别混，关系到你认不认得客户）：主母线是柜顶贯穿、把一排柜并联起来的铜排；母线桥是两排柜之间跨接的铜排罩壳；母线槽是低压大电流远距离送电用的封闭铜排"通道"，属结构件、里面基本不放继电器。所以只做母线槽/电缆桥架的厂不是目标客户（没有二次回路），做开关柜、箱变、直流屏的才是。
  • 端子排 / 端子：二次接线的中转站，继电器经端子接入柜内回路。客户说"端子排不够用/太挤"= 推可拔插式省端子的机会。
  • 光字牌：柜门上写着"断路器跳闸""SF6 报警""控制回路断线"的发光窗，由信号报警器（FA）驱动——客户提"光字牌""事故音响""警铃"= FA 的活。
  • 中央信号 / 事故总信号：全站报警的汇总（警铃+光字+送后台），是信号报警器的主战场。
  • 合闸红灯 / 跳闸绿灯：柜面指示灯，红=合位、绿=分位，串在位置继电器触点回路里。
  • 控制回路断线（控制回路断线告警）：TWJ 和 HWJ 都不励磁 = 回路失电——电网最常见的告警之一，背后就是位置监视继电器（RL-THW）的应用逻辑。
  • 联锁 / 闭锁：防止误操作的逻辑关联（如隔离开关未分不许合接地刀）；闭锁=强制禁止。闭锁回路里继电器的用法（如 SF6 闭锁、低气压闭锁）你要能接上话；成套柜强制的"五防"及其机械闭锁/电气闭锁怎么实现，见 B.5。
  • 我们在这（二次回路）：RL-THW 跳合位监视（TWJ/HWJ、控制回路断线告警）、RDP 双位置继电器（需要失电保持的两态位置重动）、FA 信号报警器（光字牌/中央信号）、RC 中间继电器（出口/信号放大回路）。

4.5 温控与测温场景（DTC/TC/TCC/TK 的"家"）

  • PT100 埋件：干变三相高压绕组里预埋的铂电阻测温点（每相 1~2 只，高端的低压绕组/铁芯也埋），引线到温控器。
  • 冷却风机（横流风机）：干变底部或侧面的散热风扇。温控器分级动作：预警（一级温度告警）→ 启动风机（二级）→ 跳闸（三级超温直接跳断路器）——这就是你向干变厂讲 DTC/TC 时的标准话术。
  • 风机报警器（TCC）：风机本体也要被监视——风机停转/断线就报警。干变配了风机却没配风机监视 = 客户的盲区，主动提。
  • 第四路测温：DTC 支持三相绕组+第四路（环境或铁芯）——高配干变测点多，报价时问清埋了几只电阻。
  • 超温跳闸 / 温度远传：绕组到跳闸值输出跳闸；同时把温度变送成 4-20mA 送后台（TT 温度变送器的活，或选带模拟量输出的 DTC）。
  • 热电偶采集器（TK）：电厂、工业现场几百上千度的高温测点用热电偶，四路采集、四路超温告警——别拿 PT100 的产品去接热电偶，测温元件分场景。
  • AN / AF（自冷 / 风冷）：空气自冷 / 强迫风冷。自冷干变也建议装温控器做监视（只监视不启风机）——这是干变厂做自冷款时的隐性需求，别漏。
  • 我们在这（干变测温场景）：DTC/TC 干变温控器（三相+第四路测温、启风机、超温跳闸）、TCC 风机报警器（风机断线监视）、TT 温度变送器（温度 4-20mA 远传）、TK 热电偶采集器（高温测点）。

4.6 温湿度、凝露与挡位场景（THC/THS/TG 的"家"）

  • 凝露 / 驱潮：柜子昼夜温差会在柜内结露（凝露）→ 爬电、闪络事故。温湿度控制器（THC）检测到凝露风险自动投切加热器（驱潮）——开关柜、端子箱、汇控柜内标配。听到客户说"凝露""驱潮""柜内加热"= THC 的机会。
  • 温湿度上传：客户要把柜内温湿度传后台/平台——温湿度变送器（THS）输出 4-20mA 或 RS485，和 THC（本地控制）是两回事：一个管"上传看得见"，一个管"自动投加热"，很多场景两个都要。
  • 有载调压 / 挡位：变压器带有载分接开关（OLTC）可以不停电调压（调输出电压挡位），挡位信号要传给后台/挡位表——挡位变送器（TG）就是把挡位转成 4-20mA 输出的（用有载调压变的电厂、变电站是它的客户）。
  • 我们在这（温湿度/挡位场景）：THC 温湿度控制器（本地检测凝露自动投加热器驱潮）、THS 温湿度变送器（柜内温湿度 4-20mA/RS485 上传后台）、TG 挡位变送器（有载调压挡位远传）。记住分工：THC 管"本地自动动作"，THS 管"上传看得见"，很多柜子两个都要。

4.7 电源与变压器场景（YDSP/DPM/XF 的"家"）

  • 柜内直流供电：柜子里一堆继电器、变送器、温控器都要直流电吃饭——开关电源（YDSP）就是把柜内交流变成稳定直流的"食堂"。交流 100~240V 输入，输出 110VDC/220VDC，120W~1000W 四档。卖继电器时顺手问一句"柜内直流电源用谁的"——元件越多电源功率越大，捆绑机会。
  • 冗余供电：重要负载（保护、监控、通信）不能断电——两台开关电源 + 二极管冗余模块（DPM）并联，一台故障另一台无缝顶上。客户说"供电冗余""N+1""重要负载不能掉电"= DPM 的机会。
  • 控制变压器（XF）：380V 转 100V 等电压等级转换，负载阻抗 ≥50K、精度 1%——进口设备、特殊电压等级仪表、老系统改造会点名要。单相三相可选。
  • 双电源切换：箱变、户外柜、通信站点常有两路进线——双交流/双直流电源切换继电器（RVS/RVS-DC）自动切换，AC1 失电秒切 AC2、恢复自动切回。客户说"双回路供电""两路进线自动切"= RVS 系列；这类自动切换设备行业统称 ATSE（Automatic Transfer Switching Equipment，双电源自动转换开关），听到 ATSE 也是它。
  • 我们在这（电源场景）：YDSP 开关电源（柜内交变直供电）、DPM 二极管冗余模块（双电源并联不断电）、XF 控制变压器（380V 转 100V 等电压转换）、RVS/RVS-DC/RMS 双电源切换继电器。

4.8 新能源场景（光伏/风电/储能/充电桩——现在最肥的客户群）

  • 光伏电站（一步步看每个设备里有什么）：
    • 汇流箱：把若干串光伏板电流汇成一路，内含熔断器、断路器、防反二极管、通信模块——我们在这：THC 温湿度控制器（户外箱防凝露）、RS485 通信配套、小型中间继电器 RC。
    • 逆变器：直流变交流，IGBT 功率器件发热大、控制板娇贵——我们在这：温度变送器 TT（测 IGBT/进线温度）、THC 柜内温控、YDSP 开关电源（给控制板供电）。
    • 箱变：升压到 35kV——我们在这：DTC 干变温控器、RL-TBJ 防跳、RDP 双位置、THC、YDSP。
    • 升压站：全站直流屏 + 保护屏——我们在这：直流屏全家桶（RMY/RDP/FA/YDSP/DPM）。
  • 风电场：机舱（变桨、偏航、主控柜——我们在这：控制柜 RC 中间继电器、TT 温度变送器测齿轮箱/发电机温度、THC 防凝露）；塔筒（电缆、升降机控制、环境监测——我们在这：THS 温湿度变送器、THC 驱潮）；箱变 + 升压站（同光伏）。
  • 储能电站：先认三个缩写——PCS＝储能变流器（Power Conversion System，交直流变换）、BMS＝电池管理系统（Battery Management System，管每簇电池）、EMS＝能量管理系统（Energy Management System，全站调度）。PCS 舱（变流器+控制柜——我们在这：控制柜 RC 继电器、温度变送器、YDSP 开关电源）；电池舱（电池簇 + BMS，怕热怕湿怕烟雾——我们在这：THS 温湿度变送器、THC 驱潮、FA 信号报警器（温度/烟雾告警联动））；升压站/箱变（同上）。储能的用量为什么比同规模传统配网大（估容量时心里有数）：电池是一簇一簇并起来的，每一簇都有 BMS 从控，要供电、要测温和上传，所以温湿度/温度测点、信号报警、控制继电器会随电池簇数、模组数叠加；PCS 常多台并联，每台都有自己的控制、供电和切换回路，控制继电器、开关电源随 PCS 台数叠加；每个预制舱还有舱级环控（防凝露、驱潮、烟雾告警）和一套舱内直流供电。所以估储能客户别只按"几个舱"毛估，要问清电池簇数、PCS 台数、舱数三个量——真实颗数仍以舱内二次图 / BOM 为准，这里只帮你看懂"用量从哪多出来"。
  • 充电桩 / 充电站：交流桩（小功率，控制板+计量——我们在这：TE 电量变送器（计量）、YDSP）；直流快充桩（整流模块+控制板，模块发热大——我们在这：TT 温度变送器（模块温度）、YDSP 辅助电源、THC）；充电场站箱变（同上）。客户做充电桩/充电堆=电源类+温度类产品的稳定客户。
  • 氢能/制氢（新赛道，提前占位）：电解槽+整流电源+控制柜——我们在这：整流柜温控、YDSP、变送器。目前量小，但客户跑起来后先入为主。
  • 新能源一句话总结：这些场景本质都是"柜子+测温+供电+通信"的组合，我们的五大类产品（继电器/变送器/温控/信号报警/电源）在每一个环节都有位置——见到新能源集成商，按"柜内供电 YDSP + 测温 TT/THS + 防凝露 THC + 控制继电器 RC"一整套报。

4.9 工业与楼宇场景（传统行业的基本盘）

  • 消防泵控制柜 / 排烟风机控制柜：消防泵、排烟风机要求双电源+自动启动（顺序启动/互锁）——我们在这：RVS 双电源切换、RT 时间继电器（顺序启动）、RC 中间继电器（互锁）、FA 信号报警器（消防联动信号输出）。注意：消防类产品部分要消防认证（CCCF），报价前先确认客户要什么证。
  • 电梯控制柜：曳引机控制+门机控制+平层——我们在这：RC 中间继电器、RT 时间继电器、双电源切换 RVS（电梯两路电）。电梯厂继电器用量大且常年稳定。
  • 起重 / 行车 / 港口机械：起升、行走、变幅机构控制——我们在这：RC 中间继电器、RT 时间继电器、RAI 抗干扰继电器（大电流起吊瞬间干扰大，普通继电器容易误动）。
  • 泵站 / 水处理：水泵控制柜——我们在这：RT 时间继电器（水泵顺序启动）、RC 中间继电器、TE 电量变送器（电流/压力上传）、THC 柜内防凝露（泵房潮湿）。
  • 数据中心 / 机房：UPS + 列头柜 + 配电柜——我们在这：TE 电量变送器（电能质量监测）、YDSP 开关电源、FA 信号报警器、THS 温湿度变送器（机房环境）。
  • 通信基站 / 一体化户外机柜：5G 基站、户外通信柜——我们在这：THC 温湿度控制器（户外柜必凝露，标配加热）、THS 温湿度变送器、YDSP 开关电源、RVS 双电源切换（基站常有两路市电）。
  • 矿山井下：防爆配电设备、强干扰环境——我们在这：RAI 抗干扰继电器、THC 防凝露（井下潮湿）。井下还有防爆认证要求，先问客户要什么证。

五制造模式：OEM / ODM / OBM / JDM贴牌与代工全家桶

这是客户问得越来越多的一组词，尤其客户想"做自己的牌子"或者想把你的产品装进他家设备里转卖时，一定会蹦出来。四个字母之差，含义天差地别。

5.1 OEM（Original Equipment Manufacturer，贴牌代工）

  • 大白话：客户出品牌、出技术要求（图纸/规格书），你只负责按他的要求生产，产品打他的牌子。
  • 例子：某干变厂要求你按他们的规格生产温控器，丝印（产品上的字）打他们厂的 logo，出厂后当"他们家的温控器"卖给下游客。
  • 特点：技术规格是客户定的，你赚的是制造加工费；客户掌握"设计权"。
  • 对你意味着什么：客户问"你们能做 OEM 吗？"= 给你贴牌订单。接 OEM 单通常要谈三件事：最小起订量（MOQ）、丝印/包装定制费、是否签保密协议（NDA）。我们做 OEM 是纯赚产能的钱，但要防客户拿你的方案去比价。

5.2 ODM（Original Design Manufacturer，原创设计制造）

  • 大白话：你出产品设计（现成产品线），客户挑中后贴他的牌子卖。
  • 例子：客户看中你目录里的 DTC 温控器，不改设计，只要求打他的 logo——这就是 ODM。
  • 特点：产品是你的，品牌是他的。对你意味着什么：这是利润最好的贴牌模式——公司已有完整产品线，接 ODM 单几乎零开发成本，卖的还是你的标准品。

5.3 OBM（Original Brand Manufacturer，自主品牌）

  • 大白话：自己设计 + 自己的品牌 + 自己销售，从头到尾都是自己家的。公司现在走的路就是 OBM。
  • 对你意味着什么：向客户强调"我们是自主品牌制造厂，不是贸易商"——贸易商（只倒手不生产）在客户眼里加分低，OBM 工厂加分高。反问客户"贵司这个产品是自研还是贴牌的"，能快速摸清对方在产业链的位置。

5.4 JDM（Joint Design Manufacturing，联合设计制造）

  • 大白话：双方一起出人出技术，共同开发一款定制产品，产权/供货按合同谈。大客户提定制需求时常走这个模式。
  • 对你意味着什么：客户说"我们想联合开发一款 XX"= 大机会也大投入，先谈清楚：模具费谁出、专利归谁、是否独家供货。

5.5 一句话区分口诀（先背这个）

OEM = 你照他的方案做，贴他的牌；

ODM = 你照自己的方案做，贴他的牌；

OBM = 你照自己的方案做，卖自己的牌。

客户嘴里"代工""贴牌""定牌生产"通常泛指 OEM/ODM，追问一句"规格是你们定还是我们定"就能分清。

5.6 相关词

  • 白牌 / 中性包装：产品不打任何品牌（或包装无品牌），客户买回去自己贴。常用于客户做自己的品牌起步期——是切入 ODM 的前奏。
  • NDA（保密协议）：OEM/JDM 前客户基本都要求签。正常流程，不用怕。
  • 贸易商 / 代理商 / 授权代理：只卖不造的中间商。客户问"你是厂家还是贸易商"，答：厂家（OBM 自主品牌+自有工厂）。

六BOM 深度解析打进客户心脏的那张清单

BOM 是销售元件的人最值得搞懂的一个词：你的型号写进 BOM 的那天，基本等于锁定了一个随客户产量滚动的长期订单。

6.1 BOM 是什么

  • BOM（Bill of Materials，物料清单）：一台产品所有零件的完整清单——外壳、螺丝、线材、继电器、温控器、开关电源……每一行 = 物料号 + 名称规格 + 数量 + 供应商/品牌。
  • 客户的研发部（不是采购部）维护 BOM；它存在客户的 ERP/PLM 系统里；生产计划、采购下单、成本核算全部跟着 BOM 自动走。
  • 打个比方：菜谱之于厨房 = BOM 之于工厂。菜谱里写了要用什么牌子的酱油，厨师（采购）就买什么牌子——换酱油要厨师长（研发）签字。

6.2 BOM 的几个层级（听得懂客户内部讨论）

  • EBOM（设计 BOM）：研发图纸拆出来的清单，"设计上要什么"。
  • MBOM（制造 BOM）：加上工艺信息（怎么装、装到哪道工序），"生产上怎么用"。
  • 采购 BOM / 采购清单：从 MBOM 汇总出"要向供应商买什么、买多少"——你的订单源头。

6.3 A 点 / B 点（供应商点位）

  • 客户为防断供，同一物料常指定两家供应商：A 点 = 主选（份额大头），B 点 = 备份。
  • 客户说"你们是 B 点"= 平时基本不给你量，A 点断供才轮到你。
  • 你的目标永远是抢 A 点：从 B 点转 A 点，要抓的时机是 A 点出质量问题（8D/交付事故）或年降谈崩。

6.4 ECN / ECO（工程变更通知）

  • BOM 不是随便改的：改一个料号、换一个供应商，要走工程变更流程——研发发起、评审、重新验证（有时要重新送样甚至重做型式试验）。
  • 对你意味着什么（双刃剑）：
    • 坏消息：图纸定型后你很难插进去——换料要客户走一圈 ECN，谁都不想惹这个麻烦。
    • 好消息：一旦你进了 BOM，竞争对手想把你换掉同样要过 ECN 这道坎。所以客户说"图纸定型了"，你的正确动作是攻他们的"下一代产品"（新品立项时 BOM 还是敞开的）或备件渠道。

6.5 替代料 / 同等替代（OR Equivalent）

  • BOM 里某一行可能写"XX品牌 或 同等（OR equiv.）"——意味着有弹性空间。
  • 挤进"同等"名单比硬换 A 点容易得多，是替代进口件（菲尼克斯、魏德米勒等插拔式接口继电器）的常用通道。

6.6 从送样到进 BOM 的完整路径（背下来）

  1. 送样（免费样品 + 规格书 + 检测报告）
  2. 上机测试 / 小批量试用（客户产线验证）
  3. PPAP / 批产认可（汽车行业词，工业客户类似流程：提交全套文件证明你能稳定量产）
  4. 量产导入（MP）：研发把你的物料号写进 BOM，ECN 发布
  5. 稳定供货 → 争取份额提升（B点→A点）→ 应对年降

客户说"图纸定型了"卡在第 4 步之前；客户说"下个平台/下一代在规划"= 第 1 步的入口敞开着。

  • CRM：销售用的客户管理系统。你自己的公司也可能用。
  • WMS：仓库管理系统。
  • OA：办公自动化（内部审批流）。客户说"流程在 OA 里走"= 内部审批中，催也没用，等。
  • 电子采购平台 / 电子商城：国网商城、客户自建商城等。"这单走商城"= 价格流程全部线上化，先完成平台入驻。

九采购流程与商务名词决定你单子怎么成

9.1 询价与下单链路（一图记牢）

PR（采购申请，客户内部发起）→ RFQ（询价单，发给你）→ 报价 → 询比价/招标 → PO（采购订单）→ 合同 → 交货 → 对账 → 开票 → 回款

  • RFQ（Request For Quotation，询价单）：客户正式发来的询价文件，常带规格书/图纸。收到 RFQ ≠ 拿单，只是入场券；但客户发 RFQ 给你而不是别人，说明你已经进了短名单。
  • PO（Purchase Order，采购订单）：客户下的正式订单。收到 PO 才是真正的成交信号——口头答应/邮件意向都不算。PO 上的价格、数量、交期、账期是结算依据。
  • 交期（Lead Time，交付周期）：下单到交货的时间。客户常问"交期多久？"——交期快是小厂打大厂的经典武器，尽量备常用规格半成品。
  • MOQ（最小起订量）：接单的最小数量。做 OEM/定制时你要报 MOQ（比如定制丝印 MOQ 500 台），否则客户要 50 台你也得开产线。

9.2 采购方式

  • 询比价：客户发询价函给几家供应商，比完价直接定——门槛最低的采购方式，你的主攻模式。
  • 招标 / 议标 / 单一来源：公开招标（走流程文件）；议标（小范围谈）；单一来源（指定一家）。你找"不走招标的客户"，就是找能询比价/直采的。
  • 集采：集团层面集中采购（如国网集采、大型电气集团集采）。量大但流程重、账期长，集团化大客户多走这种模式。
  • 直采/自采：事业部/车间自己决定买谁的（不走集团流程）——最好切入的口子。

9.3 供应商准入

  • 合格供应商 / 入围：进入客户"合格供应商名录"（也叫短名单），之后才能被询价。很多客户第一单不是卖出来的，是"注册+审厂+送样"通过后自动来的。
  • 送样 / 打样 / 样件：免费提供样品给客户测试。"送样通过"是进图纸的前奏。
  • 审厂 / 验厂：客户来你的工厂实地检查产能质量体系（SQE 带队，查体系文件、产线、检测设备）。客户提出审厂=认真想合作了，是好消息。
  • 供应商年度审核 / 年度评级：大客户每年复审一次，评级（A/B/C 或优秀/合格/整改）。C 级/整改 = 份额会被砍，也是抢 A 点的时机窗口。

9.4 采购条款类

  • 框架协议：先谈好一年的价格和量，按需分批下单——续单最容易的形式。
  • 长协（长期协议）：多年度的框架协议，比一年期更稳。
  • 年降（年度降价）：大客户对供应商的年度降价要求，常见 3%~5%。谈判筹码：用年降换份额提升、用年降换 A 点。 听到"年降5个点"别直接答应——要拿到量承诺再让。
  • 寄售 / VMI（供应商管理库存）：你先把货放到客户仓库，客户用了才结算。压的是你的资金和库存风险，小客户别轻易答应；大客户可换长期锁定的量。
  • JIT（准时制交付）：客户要你按他的生产节奏小批量高频送货。接 JIT 前确认自己备货能力。
  • 安全库存 / 备货：客户说"先备点货"——让你承担库存。要谈：备多久、滞销料谁消化。
  • 分批交货：一个 PO 分几批发，常见于项目型订单。
  • 评标 / 中标候选人公示：招标流程术语。"中标候选人"=拟成交但还没最终定。

9.5 报价单必填清单（少填一项后面就扯皮）

报价单是法律文件，每一条都是后面对账、催款、扯皮的依据。发出前逐项核对：

十财务、发票与回款别在钱上露怯

技术谈得再好，最后栽在发票和账期上就全白干。这节是防身用的。

报价前必确认 6 件事（少问一件，后面就有一个坑）

① 含税还是未税——13% 专票差 13 个点，直接吃掉毛利（见 10.1）；② 运费谁出——含运还是到付，报价单写死，别"到时候再说"；③ 账期 / 预付——新客户尽量款到发货或预付 30%+（见 10.2）；④ 开什么票、抬头开谁——专票普票、三流一致（见 10.1）；⑤ 质保与质保金——质保几年、押多少比例、何时释放（见 10.2）；⑥ 货期——客户要的日期能否满足、超期怎么算，别拍脑袋承诺。

10.1 发票

  • 增值税专用发票（专票）：13% 税率的可抵扣发票，一般纳税人客户必须要这张才能抵扣进项税。
  • 增值税普通发票（普票）：不能抵扣。小规模纳税人客户可能只要普票。
  • 客户说"发票要 13 个点的" = 要 13% 增值税专票。报价前必问含税与否，否则 13 个点直接吃掉你的毛利。
  • 含税价 / 未税价（不含税）：报价单一定要写清楚。同样报 100：含税 100 = 实际货款 88.5，未税 100 = 客户实付 113——差距巨大，报价前必确认。
  • 三流一致：合同流、货物流、发票流必须一致（合同签 A 公司、货发给 B 公司、发票开 C 公司 = 违规）。客户要"发票开到我们关联公司"时务必谨慎，坚持三流一致。

10.2 付款方式

  • 账期：先货后款的天数（30/60/90 天账期）。对你这种跑新客户的：新客户尽量款到发货或预付。
  • 预付款（预付）：下单先付一部分（30%~50%），新客户最安全的开局。
  • 款到发货（现款现货）：最保守也最安全。
  • 承兑汇票（银承 / 商承）：
    • 银行承兑：银行担保到期兑付，基本安全但有期限（3~6 个月常见），急用钱要贴现（贴现 = 提前取钱，银行扣利息）。
    • 商业承兑：只靠企业信用担保——房企、资金紧张客户的商承约等于白条，能拒就拒。
    • 客户问"走承兑可以吗"：可以接银承，但问清期限、计入账期。
  • 质保金（质保金条款）：合同总额的 5%~10% 押 1~2 年，质保期满无质量问题才付。项目型订单的标配，报价时要把它算进现金流。
  • 履约保证金 / 投标保证金：投标时交的押金。投标保证金法定上限为项目预算 2%，未中标必须退还；履约保证金一般 ≤ 合同额 10%，常用保函代替。
  • 保函（银行保函）：让银行替你担保，交少量保证金就能开出，代替现金保证金——投标多时必备工具。
  • 挂账 / 应付账款：客户收货入账后进入"挂账"状态，等账期到点付款。客户说"已经挂账了"= 货他们认了，钱在排队——记录账期起算日，到期主动对账催收。
  • 对账：双方核对应收应付明细，一般季度或半年度一次。对账单是催款和追债的基础证据。

十一质量术语SQE 对话防身

  • SQE（Supplier Quality Engineer，供应商质量工程师）：客户里专门管供应商质量的人。审厂是他带队、质量问题是他追你、8D 报告是他要——技术+质量线上的关键人物，和他搞好关系能提前知道很多内部信息。
  • IQC / IPQC / OQC：来料检验 / 制程检验 / 出货检验——工厂质检三道关。客户审厂必查你的检验记录。
  • 型式试验 / 出厂试验：型式试验=第三方权威机构对产品做的全套认证试验（贵、周期长、一般做一次）；出厂试验=每台出厂前的例行检测。客户问"有没有型式试验报告"= 问你产品有没有权威背书。
  • 检测报告 / 出厂检测报告：每批货随附的检测数据。监理和业主常查。
  • 8D 报告：客户投诉质量问题后要求你提交的"8 步整改报告"（问题描述→临时措施→根因→永久措施→效果验证→预防→总结）。写 8D 是流程，闭环它才能保住供应商资格；客户要 8D 说明还想留着你，真不想要你直接降级了。
  • PPM（百万分之不良率）：质量水平指标。元件行业不良几百 PPM 算正常，几十 PPM 优秀。
  • RMA（Return Merchandise Authorization，退货授权）：客户退货前要先申请授权号。客户提 RMA = 走正式退换流程。
  • MTBF（平均无故障时间）：可靠性指标，小时数越大越可靠。继电器常标机械寿命/电寿命（如 10⁷ 次机械、10⁵ 次电气）——客户问寿命报这两个数。
  • AQL（可接受质量水平）：抽检判定标准，客户来料抽检按它执行。
  • 开箱合格率 / 上机直通率：客户拆箱即不良 / 上产线一次通过的比例。这两个数字难看，IQC 直接退货。
  • 质保期 / 保修期：本公司产品标准质保期为购买或交货后 1 年，合同可另行约定更长（如 24 个月），以合同条款为准、别空口承诺两年。质保起算点也要谈：发货日起 or 到货签收日起——差几个月，务必写进合同。

十二资质与标准你的"敲门砖"体系

  • CCC认证：中国强制性产品认证，按认证目录管理，只有列入强制性认证目录的品类才必须取证。低压电器里断路器、接触器、熔断器、热继电器、低压成套开关设备等在目录内；中间、时间、控制类继电器多数不在 CCC 强制目录，通常用 CQC 标志认证加型式试验报告作质量背书。别对客户笼统讲继电器都有 CCC，具体哪个品类持 CCC、哪个走 CQC，以公司有效证书为准。
  • CQC认证：中国质量认证中心的自愿性认证。很多招标文件写"CCC 或 CQC"——没有 CCC 的品类靠它补位。
  • 国网/南网入网：进入国家电网/南方电网采购体系的资质门槛，分品类、有有效期。对外提之前必须回公司确认证书是否覆盖你要报的产品、是否在有效期——确认有再讲，这是对电网侧客户的强卖点；没核实就只讲型式试验报告和产品参数，绝不能把"在办/过期"说成"已有"。
  • 型式试验报告：国家级检测机构（如国网电科院、西高所）出具。客户认可度最高的单件资质。
  • IEC / GB / DL：国际电工委员会标准 / 国标 / 电力行业标准。客户说"按GB/T XXXX做"，指的是产品依据的标准号。
  • CE / UL / TÜV / CB：欧盟 / 美国（Underwriters Lab，安规严）/ 德国（TÜV，欧洲客户认）/ 国际互认体系认证。出海客户或外资客户会点名要——看到客户做出口，主动问需不需要 CE。公司已取得哪些外贸证书、覆盖什么品类，一律以有效证书为准，别凭印象打包票。
  • RoHS：有害物质限制（欧盟环保指令），电子电器出口欧盟必备。
  • CCS / CRCC：中国船级社 / 铁路产品认证。做船海客户要CCS；做轨交客户要CRCC——这两张证是你下一阶段的敲门砖。
  • EMC：电磁兼容。抗干扰继电器（RAI）的核心卖点就是 EMC 指标。
  • CNAS 实验室：国家认可委认可的实验室（自实验室出报告带公信力）。客户问"你们实验室是 CNAS 吗"= 问你自检报告的权威性。
  • ISO9001 / ISO14001 / ISO45001：质量/环境/职业健康安全管理体系。审厂第一道查的就是这三张，年审记录要齐；公司具体取得哪几张体系证书、是否在有效期，以有效证书为准。
  • 专精特新 / 小巨人 / 瞪羚企业：工信部/地方给成长型企业的官方评级——看到目标客户有这些头衔=官方盖章的优质成长客户。
  • 国家高新技术企业：科技部认定的技术型企业资质，属于企业综合资质，招投标里可能加分——听到客户提这个词，知道是在讲企业资质门槛即可。
  • 对外报证的统一口径：上面每张证都有覆盖的产品品类和有效期，投标或对客户承诺前，先回公司核对证书在有效期内、且覆盖你要报的型号；拿不准就只讲"我们做了对应型式试验、可以提供报告"，别把"在办、过期、不覆盖该品类"说成"已有"。

十三招投标全流程看懂客户的"走流程"

13.1 完整时间线（从公告到回款）

招标公告发布 → 购买/下载标书 → 制作投标文件 → 递交投标 → 开标 → 评标 → 中标候选人公示（不少于 3 日）→ 中标通知书 → 签合同 → 履约 → 验收 → 结算（扣质保金）

  • 招标控制价 / 拦标价：招标方公布的预算上限，报价超过直接废标。拿到标书第一件事就是找这个数。
  • 技术标 / 商务标：投标文件两部分——技术方案（参数、业绩、资质）+ 商务报价。常分两信封，技术标先评，不过关商务标不拆（俗称"技术废标"）。
  • 最低价中标 / 综合评分法：两种评标规则。最低价=纯拼价格；综合评分=价格+技术+业绩+服务加权打分（资质、型式试验报告和技术方案在综合评分法里能换回价格劣势）。
  • 废标：投标文件不合规矩直接出局（资质缺、装订错、迟交、超控制价）。细节杀手，投标文件必须专人复核。
  • 围标 / 串标：几家串通围住价格——违法，别碰。客户暗示"找两家陪标"，直接拒绝。
  • 联合体投标：两家组队一起投（如你 + 成套厂）。
  • 授权委托书 / 法人授权：投标代表要带的法律文件。
  • 中标候选人公示：第一名的"预备"状态，依法必须招标的项目公示期不少于 3 日，期内无异议、无投诉才算真中标。
  • 中标通知书：正式成交确认，之后才签合同。"我们中了"要等这张纸才算数。

"先备点货 / 做点安全库存"让你垫库存谈框架协议锁定量，或限定备货额度
"已经挂账了"货入库、款在账期队列里记账期起算日，到期前一周主动对账催款
"你们是 A 点还是 B 点"问你在 BOM 里是主选还是备份如实答；是 B 点就盯 A 点质量事故的切换窗口
"这个要走 ECN"换料要走工程变更准备全套对比资料帮研发降低变更成本——帮他省事就是帮自己
"走 OA 了 / 在 OA 里"内部审批中别催，约节点提醒
"签个框架"想谈框架协议好事，谈价、量、有效期、自动续约条款
"二次室太挤"开关柜继电器室空间不足推小型化/可拔插系列（RC 系列小体积型号）
"柜子凝露/驱潮"户外柜内结露要加热器推 THC 温湿度控制器
"做一套直流屏"客户做直流电源系统报全系列：电压监视、双位置、信号报警器、开关电源

"两路进线要自动切"双电源自动切换推 RVS/RVS-DC/RMS 电源切换继电器

十五常见异议与应对客户说不，你怎么接

客户说"不"不一定是不想买，往往是没听明白或没看到价值。每句应对都按"接住情绪 → 给事实 → 给下一步"三步走。

客户说真实心理你怎么接
"太贵了"想要更低价，或没看到价值先问"您是和哪个品牌比？"——拆开对比参数与寿命；再给总成本账（单价×用量×年用量）；最后给台阶：量起来可以谈年降
"你们是国产小厂，质量行吗"怕担责、怕不稳定不辩解，直接摆事实：CQC/CCC、CE/CB 等证书与型式试验报告、关键参数对比；主动提出送样+上机测试，让产品自己说话
"我们一直用进口的（菲尼克斯/魏德米勒）"习惯、怕换出问题承认进口的优点，再给"同等替代"方案：参数对比表逐项对照，先小批量试用，不行不勉强——用降风险方式降低换供应商的心理门槛
"图纸定型了"不想折腾 ECN不硬推，转攻下一代/新平台立项，或备件渠道
"先拿别人样品比比"还没信任你主动送样+参数对比表+型式试验报告，把"比"变成"按你的标准比"
"现在没预算 / 再说吧"时机不对或没需求不逼单，登记需求、记下他的立项/采购节奏，按节点跟进
"我们和别家合作很久了"有稳定供应商求做 B 点/备份，等 A 点出问题或年降谈崩的窗口
"这个东西我们自己能做"想自己干或压价不算账，先问"你们是批量做还是自用？"——自用不如买，批量做不如找专业厂，成本、测试、认证都是门槛
"再降 5 个点就下单"试探底价不裸降：降可以，换条件——提量、预付、账期缩短、签框架，任何一条都比干降价值钱
"你先放一批货试试"想零风险试用可以，但限定数量与期限，签试用协议，试完要么转正式单要么退回

消防联动
消防泵/排烟风机双电源+顺序启动 → RVS+RT+RC+FA
控制变压器
380V 转 100V 等电压转换，XF 系列的应用位
三工位
环网柜/充气柜负荷开关的三个位置：隔离合—分闸—接地合，一把刀切换；分两层记——位置反馈后台没有"三工位位置继电器"，用双位置/中间继电器按辅助接点组合（常见2只、以图为准）；电动操作机构的电机控制才有专用 RN-DK-C
RN-DK-A
两工位刀闸（隔离开关，只有分/合）电动机构控制模块：驱动1个串励电机正反转、外接制动电阻，带过载和超时保护，电机≤800W；管电机怎么动，不是位置继电器
RN-DK-C
三工位刀闸电动机构控制模块：驱动隔刀+地刀2个永磁电机（单台≤600W），内置三态联锁（隔离合只响应隔离分、接地合只响应接地分），无制动电阻；位置反馈仍另配组合继电器
五防闭锁
成套柜强制的五道安全联锁（防误分误合、带负荷拉刀闸、带电挂地线、带地线合闸、误入间隔），闭锁回路=继电器硬需求
真空断路器
10kV 主流开关，靠真空泡灭弧；你供的防跳/合保/跳位监视就装在它的操作回路里
VS1 / VD4
KYN28 里最常见的手车式真空断路器（VS1 国产主流、VD4 是 ABB），客户说"配 VS1"就是它
SF6 六氟化硫
高压柜/GIS 用的绝缘灭弧气体，气压低要报警闭锁 → RN-FT 低气压闭锁继电器
充气柜（C-GIS）
高压带电体全密封进气箱、充 SF6 或环保气体的中压柜，全密封免维护；按绝缘命名，和按用途命名的"环网柜"是两个维度、有交叉；只有 SF6 柜才用 RN-FT 气压闭锁，只有断路器型才用防跳
固体柜 / 环保气体柜
固体=环氧浇注封死、无气体；环保气体=干燥空气/N2 替 SF6；都没有 SF6 气压闭锁，其余元件用法同充气柜
高压柜型号命名
K铠装/J间隔/X箱式 + Y移开/G固定 + N户内/W户外 + 序号-电压(kV)，前缀 H=环网；KYN28-12、HXGN15-12 当场拆开听
隔离/站用变/避雷器柜
隔离柜给明显断开点不切负荷；站用变柜给本站自用电；避雷器柜吸收过电压；都有位置/信号/防凝露零散用量
JP 柜
柱上变压器下方的低压综合配电箱，配电+计量+无功补偿+漏保一体，农网/台网改造标配
母线 / 母线桥 / 母线槽
主母线柜内并联、母线桥跨接两排柜；母线槽是低压大电流封闭通道、属结构件基本不放继电器——只做母线槽/桥架的厂不是客户
CB/VCB/LBS/DS/ES
一次开关代号：断路器/真空断路器/负荷开关/隔离开关/接地开关；VS1 就是一台 VCB
二次图文字符号
QF断路器、KM接触器、FR热继、KA中间、KT时间、KS信号、SB按钮、SA转换开关、HR红/HG绿灯、YC合/YT分闸线圈、XT端子排
SVG/APF/SVC
电能质量柜：SVG 静止无功发生器、APF 有源滤波、SVC 静止无功补偿，都是电容补偿柜的同类/升级
ATSE/UPS/EPS/GZDW
ATSE 双电源自动转换、UPS 不间断/EPS 应急电源、GZDW 直流屏；配网终端 DTU/FTU/TTU＝站所/馈线/配变
箱变（箱式变电站）
把变压器+高压柜+低压柜塞进一个箱体，分欧式/美式；每台都是成套件+干变温控的整单
移开式 / 固定式
手车能摇出来=移开式（KYN28），断路器固定装死=固定式（XGN）；两种都要操作回路继电器
弹簧储能
断路器合闸前先由电机把弹簧拉紧"上弦"，储能到位/未到位要做指示和闭锁
PT/CT（新标 TV/TA）
PT/TV 取电压（PT 切换用 RVSD）、CT/TA 取电流（喂给量度继电器），新老标注指同一个东西
操作回路（二次回路）
控制断路器分合闸的那套弱电回路，防跳、合保、跳/合位监视全在这——你的主战场
低压成套柜
0.4kV 的 GGD（固定）和 GCS/GCK/MNS（抽屉柜）；MNS 抽屉柜里中间、时间继电器最密
干变温控
干变配的温控箱：测三相绕组温度，到点启风机、再高报警、最高跳闸 = DTC 干变温控器
电缆分支箱 DFW
路边把一路电缆分成几路的铁箱子，配网改造量大，负荷开关+位置指示用小型继电器
一二次融合
把一次开关和二次 DTU/保护做成一体（环网箱、柱上开关），国网主推方向，分立元件被压缩——见到心里有数
微机综保 vs 分立继电器
综保把采样、判断和一部分出口集成进一块装置，会压缩一部分中间/量度继电器；但操作回路、位置重动、硬联锁、老柜改造仍常在装置外配独立继电器。先问客户走哪条路线、再对着二次图数，别一听综保就判定没机会（分层见 3.1.3）
